# The Vernacular — closing the prose leak

**Status:** Draft for G3 review · **Date:** 2026-07-31 · **Branch:**
`campaign/the-vernacular`

Hornvale generates a world and then describes it in English that was written
by hand, at compile time, in `match` arms and `&'static str` tables. The
concept registry, the per-culture lexicon, the clause realizer and the
register seam all exist and are all bypassed by nearly every surface that
speaks. This campaign closes that seam for the phenomenon channel and leaves
behind an enforcement lint so it does not reopen.

## 1. The defect, measured

The leak is not merely cosmetic. English prose is a **load-bearing
inter-domain semantic channel** that nothing declares and nothing protects.

`windows/worldgen/src/lib.rs:3478` decides which concept a phenomenon glosses
to — and therefore what a people's deity is named — by grepping the
phenomenon's English display sentence:

```rust
CELESTIAL_BODY => {
    if phenomenon.description.contains("moon") { Some("moon") }
    else if phenomenon.description.contains("star") { Some("star") }
    else { Some("sun") }
}
```

`windows/lab/src/metrics.rs:4252` carries a second copy, deliberately
duplicated so `name-gloss-true` cross-checks worldgen rather than echoing it.
Both dispatch on prose.

**The experiment.** On `campaign/the-vernacular`, one string in
`domains/astronomy/src/provider.rs:1610` was reworded from `"a {} moon"` to
`"a {} lunar disc"` — a change with no semantic content whatsoever — and seed
42 was regenerated:

```
world of seed 42 written (26309 facts; village: Gootoogotoodaoka)
deity-name    moved 9 of 48    Tabo -> Toa, Mzaxdzhofngsa -> Mzaxdzhofngshofngzaf, ...
deity-epithet moved 7 of 48    Vngaadootootaboa -> Vngaadootootoa, ...
TOTAL facts differing: 73
```

Seventy-three committed facts moved because a display sentence was reworded.
No stream label changed, no derivation was intended to change, and nothing in
the gate would have explained why. The experiment has been reverted; the
working tree is clean.

This is the campaign's justification. Everything below follows from it.

## 3. What counts as world text

The scope is defined by a five-branch taxonomy. Only branches A–D are world
text; **branch E is out of scope and must be explicitly exempt**, or the
campaign over-scopes by roughly an order of magnitude (`windows/worldgen/src/lib.rs`
alone holds ~227 non-comment prose literals, most of them branch E).

- **A — Referential.** Names a thing that exists in the world: a moon, a
  hearth, a farmer. → concept id + lexicon. Owner: the concept registry
  (decision 0025, one concept one owner).
- **B — Quantitative.** A count, a magnitude, a period: "three", "vast",
  "about 200 mm". → **not a word lookup, a codec.** Owner:
  `domains/language/src/numeracy.rs` plus a magnitude register.
- **C — Relational / spatial.** "in the northern sky", "over a trough", "ways
  on: E, Nw". → needs an observer-relative **frame**, not vocabulary.
  **Owner today: nobody.** This is why Earth-centrism concentrates here.
- **D — Evaluative / affective.** "oppressive heat", "smoldering red",
  "unremarkable ground". → the observer's stance. Owner:
  `domains/language/src/account.rs` (`Disposition`, `Stance`, the valence
  filter), which already exists.
- **E — Editorial scaffolding.** "Salient phenomena, most attention-demanding
  first:", markdown headers, "The land holds {} settlement(s)." Addressed to
  the reader *out of world*. **Stays English. Out of scope.**

## 4. The mechanism

**Split the field; do not structure it.** `Phenomenon.description: String`
is one slot serving four distinct roles — display sentence, semantic
discriminator, test assertion key, and dedup key
(`windows/worldgen/src/lib.rs:7512` does `seen.insert(r.description)`).
Replacing it with a richer struct keeps one field doing four jobs, which is
the actual defect. Instead:

- **`referent`** — a registered concept id, plus the typed arguments the
  rendering needs (a count, a magnitude, a period). Machine-facing. **The only
  thing a consumer may branch on.**
- **rendering** — derived one-way from the referent. Never read back, never
  post-processed, never a dispatch key.

The rule is directional and testable: content → text is permitted; text →
content is not. Nothing in the workspace may parse a rendering.

**The render ladder, and where this campaign stops.**

```
  L0  a raw literal                      <- where nearly everything is today
  L1  a registered concept id            <- lexicon-translatable
  L2  concept + grammatical features     <- ClauseSpec -> realize_common
  ----------------------------------------- campaign ceiling
  L3  + per-species voice                <- register.rs VoiceParams (exists, wired for tenets)
  L4  + listener-side account filters    <- account.rs accession stack (exists)
```

The campaign lifts branches A–D from **L0 to L1**, and routes them through
the **L2** realizer that already exists. L3 and L4 are deliberately not
reached: they exist and are wired for tenets, so re-using them later is
cheap, and extending them now is a different campaign.

**Consequence for `phenomenon_concept`.** It stops grepping prose and reads
the referent. Both copies (worldgen and the lab metric) collapse to a field
read, and the lab metric's independence — the property that makes
`name-gloss-true` a cross-check rather than an echo — must be re-established
on some other axis, since a field read cannot disagree with itself. This is
called out as a design risk in §8.

## 5. Stages

**Stage 1 — the referent field.** Add `referent` to `Phenomenon`; populate it
at all 19 producer sites; leave `description` in place and untouched. No
consumer changes. Nothing moves. Establishes the contract without risk.

**Stage 2 — flip the consumers.** `phenomenon_concept` (both copies), the
dedup key, and the `contains(...)` predicates in tests read `referent`.
`description` becomes write-only from the sim's point of view. **This is the
stage where committed facts may move** — measured, not assumed (§6).

**Stage 3 — derive the rendering.** Replace the hand-written description
strings with `ClauseSpec` → `realize_common` built from the referent. Delete
`daylight_words`, `twilight_words`, `PHASE_WORDS`, both `count_word`s (→
`numeracy`), `size_word`, `season_words`, `class_name`, `class_color`.
Register the missing concepts from §2. `region_word` and `describe`
(`figures.rs`) are **branch C** and are conditional on §8 risk 2 — if the
frame abstraction proves large they stay, and the campaign ships A/B/D.

**Stage 4 — the prose audit lint.** A standalone tool outside the workspace,
mirroring `tools/type-audit/` (decisions 0027/0028): default-deny, every
world-facing string literal must either resolve to a registered concept or
carry an explicit `prose-audit: branch-e(<reason>)` exemption tag. This is
the deliverable that keeps the leak closed; without it the 227 literals
regrow. Runs in `make gate` beside the type audit.

**Stage 5 — the book and the close.** Chronicle entry, freshness sweep,
re-score any Confidence Gradient bet this moves (decision 0030),
retrospective, census re-pin at close.

Stages 1 and 2 are separable and 1 is risk-free; if the campaign has to stop
early, stopping after 1 leaves the tree strictly better than it found it.

## 6. Determinism and the epoch question

**The referent is a save-format-class contract. The Common rendering is a
view and is not.** That distinction is the whole answer: renaming a lexeme
must become a zero-fact change, which is exactly what the §1 experiment shows
is false today.

Per **decision 0084**, no epoch is declared up front. Stage 2 *measures*
whether a committed derivation actually moved, and the answer may legitimately
be NO-BUMP. What is already known:

- `Phenomenon` appears in neither `kernel/src/world.rs` nor
  `kernel/src/ledger.rs` — phenomena are not themselves committed.
- The exposure runs through `deity-name` / `deity-epithet`, downstream of
  `phenomenon_concept`.
- The §1 experiment establishes the *magnitude* of the exposure: 73 facts on
  one seed from one reworded string.

If Stage 2's referents reproduce today's gloss outcomes exactly, zero facts
move and no epoch is owed. If they do not — for instance if a phenomenon that
currently falls through to `Some("sun")` is correctly labelled otherwise — the
epoch is real and gets declared with the measurement in hand. Declaring it
before measuring is the "empty epoch" defect 0084 names.

## 7. Preregistered measurement

Frozen here, before the code that would move it (decision 0016).

**Hypothesis.** The prose leak is load-bearing: today, a semantically null
reword of a phenomenon description changes committed facts. After Stage 2, it
changes none.

**Instrument — the reword test.** Rewrite one phenomenon description string
with a synonym; regenerate seed 42; count differing facts.

**Prediction (frozen).**

| | before | after Stage 2 |
|---|---|---|
| committed facts moved by a null reword (seed 42) | **73** (measured, §1) | **0** |
| of which `deity-name` | **9 of 48** | **0** |
| of which `deity-epithet` | **7 of 48** | **0** |

**Secondary metric — `prose-concept-coverage`.** Fraction of world-facing
string literals in branches A–D that resolve to a registered concept.
Baseline to be measured in Stage 4 when the lint can compute it; the
prediction is that the baseline is **under 20%** and the exit criterion is
**100% or an explicit exemption tag**.

A falsified prediction is a finding, not a failure. If the after-count is
non-zero, that is a real result about a channel we did not know existed, and
it ships as the headline rather than being tuned away.

## 8. Risks

1. **The lab metric loses its independence.** `name-gloss-true` is a
   cross-check today only because the two `phenomenon_concept` copies are
   written separately. Once both read one field they cannot disagree. The
   metric must be re-grounded — most likely by checking the referent against
   the concept registry rather than against worldgen's mapping. Unresolved;
   flagged for the plan.
2. **Branch C has no owner.** Spatial and frame vocabulary (`region_word`,
   compass letters, "the equator's road") needs a frame abstraction that does
   not exist. If it proves large, Stage 3 drops branch C and the campaign
   ships A/B/D — stated now so the cut is a plan decision, not a silent
   descope.
3. **The lint's exemption tag is a loophole.** `prose-audit: branch-e(...)`
   can be sprayed to silence the tool, exactly as a `waiver(...)` can in the
   type audit. Mitigation is the same one 0028 chose: the tag names a reason
   and the report is a committed, drift-checked artifact.
4. **Test churn.** Many tests assert on English (`figures.rs:330` pins
   `"northern sky"`; `provider.rs` has dozens of `description.contains(...)`).
   These convert to referent assertions plus a smaller number of honest
   rendering goldens — one brittle assertion becomes two truthful ones, but it
   is real work.

## 9. Out of scope

- **The Köppen biome taxonomy** (`temperate-forest`, `tropical-rainforest`,
  `boreal`). These are registered concepts with lexeme correspondents and are
  already translatable. Whether Earth's biogeographic ontology is the right
  one is a separate and much larger argument. → idea-registry row.
- **Branch E**, editorial scaffolding (§3).
- **Render ladder L3/L4** — per-species voice and listener-side account
  filters (§4). → followup register.
- **Earth-as-unit in author-facing frames** — `anchor-mass-earth`,
  `anchor-orbit-au`, °C/mm/W in the almanac. Legitimate as an author's
  comparison frame. The in-scope part is only where it crosses into world
  prose: `size_word`'s Luna-calibrated `"full-sized"`
  (`provider.rs:1318`) and `"× Earth's sunlight"`
  (`windows/explain/src/lib.rs:74`).
