# The Repertoire — Design

**Campaign:** The Repertoire · **Date:** 2026-07-31 · **Status:** spec, awaiting G3
· **Backlog rows:** `NARR-trope-as-probe`, `TOOL-trope-grounding`,
`TOOL-trope-prereg`, `NARR-corpus-provenance`, `NARR-three-columns`,
`NARR-mechanism-leverage`, `TOOL-graph-defects`

A repertoire is the set of pieces a company can perform without new rehearsal.
Not what it *did* perform, and not what it *should* — what it *can*. A company
that has never written its repertoire down does not know what it is unable to
stage, and cannot tell the difference between a piece it declines and a piece
it could not mount.

## 1. The problem

Hornvale has roughly six hundred registry rows of mechanism and no way to say
what the world can **stage**. "Narrative richness" is currently unmeasurable;
the only available proxy is a count of shipped features, which rewards adding
machinery whether or not anything can use it.

The inverse framing is the campaign. Read forwards, a trope is content to
generate — and `KNOW-no-mandatory-node` establishes that this does not
transfer, because a world that requires nothing has no derailment to insure
against and no node a structure must deliver. Read **backwards**, the same
artifact is a coverage probe:

> *An ambitious drow frames a superior for murder* is not a thing to generate.
> It is a conjunction of required mechanisms — ambition, a hierarchy worth
> climbing, killing classified as murder, forged evidence, others who credit
> it, a sanction, a vacancy to inherit — and whether the world supports each is
> answerable **without generating anything.**

[UNI-21](../../../book/src/frontier/idea-registry.md) already proposes the
compiled capability set, derived at load from the concept registry and the
composition-root providers. What it lacks is the **questions**. A decomposed
corpus of situations is the query language over that set, run in the demand
direction.

Two things follow that make this worth a campaign rather than a row. The
fraction of a corpus that is stageable is a single number tracking expressive
range across campaigns. And each missing mechanism carries an **unlock count**,
so the backlog acquires an ordering nobody has to argue about.

## 2. What is already pinned, and what the probe must not confound

**The vocabulary exists and is already an artifact.** `hornvale concepts` emits
124 predicates, 13 phenomenon kinds and 182 concepts into
`book/src/reference/concept-registry-generated.md`, regenerated by
`scripts/regenerate-artifacts.sh` and already inside the drift check. This is
the grounding that makes the instrument falsifiable rather than a wish list
(`TOOL-trope-grounding`).

**This is build-state, not world-state.** UNI-21 is explicit: the capability set
is derived at load, never in the world save, with no cross-version hazard. The
probe therefore touches **no seed, no world save, no epoch, no stream label and
no census**. It is a pure function of (corpus, registry) with no RNG and no
search, which is what lets it be a *test* and not only a report.

**A corpus is an instrument, not a standard.** Polti's 36 dramatic situations
are 1895 French dramaturgy; Propp is Russian folktale; TVTropes is contemporary
anglophone media. Treating any of them as the measuring stick would assert that
a culturally-situated catalogue is an inventory of the possible — the error
`PSY-five-is-lexical` names for the Big Five, one domain over. The corpus
carries provenance, and the report is a matrix, not a verdict on the world
(`NARR-corpus-provenance`).

**"Expressible" splits three ways** (`NARR-three-columns`), and this campaign
fills exactly one:

| column | claim | machinery | this campaign |
|---|---|---|---|
| **Representable** | the fact can exist | registry tokens | **yes** |
| **Generable** | an agent can plan it | GOAP over belief, `PSY-5` | no — see §6 |
| **Recognisable** | an agent can infer it happened | `UNI-abduction` | no — see §6 |

The matrix shape is established now so the other two columns are not
retrofitted later, but only the first is populated.

## 3. Decisions

**D1 — Corpus: Polti's 36 dramatic situations.** Propp's 31 functions are a
*sequence* grammar, and roughly half cannot be stated without their
predecessors; importing them imports plot-order, which `KNOW-no-mandatory-node`
says does not transfer. Polti's entries are *situations* — configurations of
role and tension — so each decomposes to a mechanism conjunction cleanly.
Greimas' six actants supply the role vocabulary for decomposition. Propp is
retained only as a filter: any candidate that cannot be stated without its
predecessors is a plot and is excluded. *(Nathan chose this against both his own
first instinct and mine; ledger #8.)*

**D2 — The corpus is data; the checker is code.** Decision
[0011](../../decisions/0011-studies-are-data-metrics-are-code.md) already settles this split for lab studies, and this is
the same shape. `tropes/*.trope.json`, mirroring `studies/*.study.json`; JSON,
not YAML (decision [0012](../../decisions/0012-config-is-json-not-yaml.md)).

**D3 — Two tiers, because leverage lives in the meets.** The requirement
structure is a lattice: situations on top, **capability bundles** in the middle,
registry tokens at the bottom. A bundle is a named set of tokens (`deception`,
`status-succession`, `lethal-violence-as-norm-violation`). Ranking by bundle
fan-in gives campaign-sized units; ranking by bare token does not.

**D4 — Verdicts are default-deny, lifted from `tools/type-audit`.** Each
requirement resolves to `satisfied(token)`, `missing(proposed-token)`, or
`waived(reason)`. A situation additionally resolves to `inapplicable(reason)`
when it presupposes something this world deliberately lacks — no marriage, so no
*Adultery*: different, not deficient. **Discipline rule: if a requirement cannot
be answered yes or no, decompose it further.** Graded verdicts are how this
decays into a wish list.

**D5 — One artifact, not two.** The report carries both the **demand** scan
(which situations are stageable; missing bundles by fan-in) and the **supply**
scan (registry tokens nothing consumes). This is not tidiness: the coverage
number is Goodhart-gameable by registering predicates nothing uses, and the
supply scan is exactly what detects that. Reported separately, the demand number
is dishonest. The two defects are TropeTwist's *Nothing* and *Broken Link*
(`TOOL-graph-defects`).

**D6 — It lives in `cli/`, as a sibling of `hornvale concepts`.** It needs the
composition root to populate the registry, which `cli/` already re-exports, and
`concepts`/`streams` are the identical shape. Not a `tools/`-style
outside-the-workspace binary: type-audit lives outside because it parses Rust
and needs `syn`/`quote`; this reads a registry in-process and a JSON file, both
inside the serde-only allowlist (decision [0004](../../decisions/0004-no-new-dependencies.md)).

**D7 — The report is the baseline; the ratchet is per-situation.** `check`
compares live output against the committed report, `REBASELINE=1` accepts — the
byte-golden pattern. The assertion is **per-situation**: *no situation that was
stageable becomes unstageable.* An aggregate percentage would let a corpus
pruning read as an improvement.

## 4. The design

### L0 — The corpus (`tropes/polti.trope.json`)

One file, provenance-stamped, 36 entries plus a bundle table.

```json
{
  "corpus": "polti-1895",
  "provenance": "Georges Polti, Les 36 situations dramatiques (1895);
                 French dramaturgical taxonomy, European theatre",
  "bundles": {
    "deception": ["predicate:...", "concept:..."],
    "status-succession": ["predicate:..."]
  },
  "situations": [
    { "id": "polti-30-ambition",
      "name": "Ambition",
      "actants": { "subject": "the ambitious one", "opponent": "the superior" },
      "requires": ["bundle:status-succession", "bundle:deception"],
      "excluded_by": [] }
  ]
}
```

`excluded_by` is how `inapplicable` is reached: a situation naming a
precondition the world deliberately lacks resolves inapplicable rather than
missing.

### L1 — The checker (`hornvale tropes`)

Two modes, mirroring `tools/type-audit`:

- `hornvale tropes check` — resolve every requirement against the live
  registry, compare against the committed report, exit non-zero on a
  per-situation regression.
- `hornvale tropes report` — emit the artifact.

Resolution is a set membership test against the three registry namespaces. An
unknown token is `missing`, never a pass.

### L2 — The artifact (`docs/audits/trope-coverage.md`)

Four sections, in this order:

1. **Provenance** — corpus, source, date frozen, and the standing note that
   this measures reach against *that* catalogue, not quality.
2. **Demand** — per-situation verdict table; the stageable fraction; the
   `inapplicable` list with reasons.
3. **Leverage** — missing bundles ranked by fan-in, each with the situations it
   unlocks. This is the backlog ordering.
4. **Supply** — registry tokens no situation requires *and* no readout consumes.

Regenerated by `scripts/regenerate-artifacts.sh`, drift-checked with the rest of
`docs/audits/`.

## 5. Preregistered predictions

Frozen before the first run. A study JSON has no hypothesis field, so per
decision [0016](../../decisions/0016-studies-preregister-hypotheses.md) the freeze lives here. **The corpus commit
lands before the first report commit**, so the git history proves the order.

- **P1 — Under 15% of Polti's 36 will be fully stageable.** The instrument is
  expected to come back red; the ranked misses are the deliverable, not the
  score. *If it comes back green, the corpus was drawn wrong and that is the
  finding.*
- **P2 — The top three missing bundles will be deception, status-succession and
  norm-violation**, in some order.
- **P3 — Corpus validity: the median bundle will be required by ≥3 situations.**
  If the lattice is flat — situations sharing few bundles — there is no leverage
  signal and the instrument is void. **This is checkable the day the corpus
  freezes, before any code, and is the cheapest available kill.**
- **P4 — At least 4 of 36 will resolve `inapplicable` rather than `missing`**,
  demonstrating that the third verdict earns its place rather than being a
  courtesy.

A falsified prediction is a finding, not a failure. Do not retune the corpus to
rescue one after unblinding; record it in the chronicle.

## 6. Non-goals

- **Generation.** No narrative is produced. `NARR-trope-graphs` gives the
  reason: a trope graph is a plot.
- **The generable and recognisable columns.** Generable needs GOAP; recognisable
  needs `UNI-abduction`, which does not exist. The report states that it
  measures only representability.
- **The endogenous corpus.** `NARR-endogenous-corpus`, `LANG-eponym` and the
  eponymy cluster describe a world coining its own named situations. That is the
  better long-term answer to the provenance problem and it is **not this
  campaign** — it needs a language-layer campaign first.
- **Verb and action tokens.** `MAP-27`'s verbs-as-reactions is unbuilt.
- **Anything per-world.** No seeds, no census, no lab study, no world save.
- **Automatic decomposition.** The corpus is hand-authored. This is the
  expensive half and it is deliberately human.
- **No new domain crate, no new dependency, no ML.**

## 7. Verification

| Claim | How it is checked |
|---|---|
| Grounding is real | every requirement token resolves against `hornvale concepts` output, or is `missing`/`waived` with a reason; no free text |
| Deterministic | `report` run twice on one tree is byte-identical |
| Ratchet holds | `check` fails when a required token is removed from the registry — **disarm it to prove it discriminates** |
| Artifact is fresh | `docs/audits/` drift check, as for the type-audit report |
| Preregistration | corpus commit precedes first-report commit in `git log` |
| Corpus validity | P3 measured at freeze, before the checker exists |
| No world-state reached | `cli/tests/architecture.rs` layering unchanged; no seed, no ledger write |

## 8. Definition of Done

- `tropes/polti.trope.json` committed, provenance-stamped, 36 situations.
- `hornvale tropes check|report` shipped; `check` wired into `make gate`.
- `docs/audits/trope-coverage.md` committed and drift-checked; regeneration
  folded into `scripts/regenerate-artifacts.sh`.
- P1–P4 scored in the chronicle, including any falsified.
- Chronicle entry (`book/src/chronicle/the-repertoire.md`) and a one-page
  retrospective (`docs/retrospectives/the-repertoire.md`, decision 0020).
- Registry: `NARR-trope-as-probe` → `spec'd`, **Where** repointed here;
  `TOOL-trope-grounding`, `TOOL-trope-prereg`, `NARR-mechanism-leverage`
  likewise. `NARR-three-columns` stays `raw` — only one column ships.
- Book freshness sweep; re-score the Confidence Gradient only if this moves a
  bet in `book/src/open-questions.md` (decision 0030) — it likely does not.
- **No census.** Nothing here touches world generation.

## 9. Candidate decision record

One choice here may deserve a decision rather than a spec section: *a trope
corpus is a provenance-stamped instrument, never a standard, and its output is a
matrix rather than a verdict on the world.* If minted, re-derive the next free
