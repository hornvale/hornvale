# The Staple D5 — decision ledger

## #1 [G1] — approach selection

**Question:** Should D5 begin by probing whether the current D2/D4 flows
already produce a city-like apex, or by designing a city mechanism first?

**Decision:** Probe first. D5 will measure whether existing dynamics produce a
comparative flow-convergence apex before authorizing a new production mechanism
or persistent city state.

**Why:** The Staple metaplan defines D5 as the apex where flows converge, with
notability derived and comparative. The standing rule requires every dynamics
rung to begin with a falsifiable Task 0 probe. Designing the mechanism first
would risk measuring whether the campaign's own assumptions can manufacture the
answer.

**Alternatives discarded:** Mechanism-first design; an absolute population or
density threshold; treating throughput alone as city status.

**Ideonomy passes / overturns:** One pass using negation, tree-finding,
substitution, atlas, and lattice. No overturn; it exposed the need to separate
comparative convergence from size, hubness, and transient throughput.

**Capture actions:** Continue the D5 design with a probe contract. Keep
population, density, throughput, catchment size, and settlement age as control
variables rather than definitions.

## #2 [G2] — probe contract

**Question:** What does the Task 0 probe count and compare?

**Decision:** Count one alive settlement in one deterministic world. Compare
all alive settlements at that rung using existing typed relation and flow
traces. The primary axis is comparative flow convergence: distinct inbound
sources, typed inbound/outbound structure, relative centrality or dominance,
and recurrence across comparable windows.

**Why:** This preserves the metaplan's comparative apex definition and D4's
boundary: a portfolio regime is evidence for specialization, not a
specialization label. It also keeps the probe on existing emitted evidence.

**Alternatives discarded:** A single scalar city score; absolute population
cutoffs; pooled whole-world totals; a visual or narrative classification with
no discriminating comparison.

**Ideonomy passes / overturns:** One prior G1 pass informed this section; no
second pass yet.

**Capture actions:** The full probe branch table, denominator, recurrence rule,
and evidence requirements remain to be specified before G3.
