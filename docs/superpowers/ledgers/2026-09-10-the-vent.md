This ledger records architectural decisions, rejected approaches, ideonomy

committed on the campaign branch and is not scratch progress.

## #1 [G1] — What is the smallest Waterworld pressure test?

**Decision:** build a compact, read-only `windows/worldgen` Waterworld overlay
at the composition root. It will derive a seabed/water-column substrate from
existing terrain and climate artifacts, add independently testable ambient
fields (light, pressure, temperature, salinity, and chemistry), derive sparse
vent sources and aggregate stocks, and expose bounded current/migration and
ordinary/diagnostic observation seams.

**Why:** Skyworld's direct typed-input boundary is already the closest proven
cross-realm shape. Terrain owns ocean/seafloor/water facts, climate owns marine
strata and ocean currents, and worldgen is the legal cross-domain composition
root. The pressure test must establish whether these inputs independently reach
outputs before any universal habitat abstraction is justified.

**Alternatives discarded:**

- A full Waterworld realm/domain with persistent ecology, metabolism, or save
  facts would promote consumers before the ambient seam is understood.
- A renderer-only vent effect would not test stocks, flows, movement, or query
  purity.
- A universal `Habitat`/"sugar" wrapper would erase the realm-specific
  meanings of light attenuation, vent chemistry, pressure, and currents.
- A full 3D fluid or planet-by-time solver would violate the bounded-work
  objective and answer a larger question than this campaign asks.

**Ideonomy passes / overturns:** three fresh passes using abstraction-lift,
cross-domain re-instantiation, tree-finding, combination, negation, and
chart/lattice/state-machine/timeline/atlas organons. No overturn. The passes
added the opposed vertical gradients (light down, chemistry up), the need to
separate source existence from source strength, and a future signal-distortion
follow-up.

**Capture:** the approved approach is specified in
`docs/superpowers/specs/2026-09-10-the-vent-design.md`. Deferred ideas are
listed in that spec and below in this ledger.

## #2 [G2] — Which Waterworld quantities are fields, stocks, and movement?

**Decision:** retain worldly nouns and use five explicit groups:

1. substrate: existing ocean/seabed classification, marine `BiomeExpr`, and
   the existing water-column/depth accessors;
2. ambient fields: light penetration, pressure, temperature, salinity, and
   chemistry;
3. aggregate stocks: plankton, chemosynthetic bloom, kelp/reef biomass, and
   nutrient reserve, with no individual organisms;
4. movement: sparse current corridors plus a bounded vertical migration phase;
5. observation: consequence-oriented ordinary output and cause-oriented
   diagnostic output.

**Why:** this is the smallest decomposition that makes the requested
independence matrix observable. It also preserves the Skyworld contract as a
reasoning aid without claiming that every realm has the same fields or stocks.

**Alternatives discarded:** one productivity scalar; a new biome enum for each
marine condition; vent placement as an authored fixed list; per-cell fluid
integration; and renderer-owned derivation.

**Ideonomy passes / overturns:** two passes, one chart/lattice pass and one
timeline/state-machine pass; no overturn. The first pass exposed that
salinity/chemistry need provenance labels because they are not interchangeable
with water kind. The second added refresh-cycle semantics without adding
lifecycle mutation.

**Capture:** implementation must prove source inequality before downstream
inequality, and must keep vent sites derived and seed-keyed rather than fixed
by vertex list.

## #3 [G4] — How should the approved Waterworld spec be executed?

**Decision:** use four stages: seam inventory and non-vacuous probes;
independent ambient fields and vents; aggregate stocks with sparse currents,
vertical refresh, and actual-loop counters; then observation, documentation,
local gate, and Sluice submission.

**Why:** each stage produces a reviewable, testable boundary while preserving
the approved scope. The first stage prevents no-op independence tests from
becoming architectural evidence; the second isolates stream and source
ownership; the third proves bounded stocks and movement; the fourth keeps
observation and generated-artifact claims evidence-backed.

**Alternatives discarded:** one large implementation task would mix source
seams, streams, stocks, movement, and rendering before failures could localize;
a plan with a universal habitat abstraction would contradict G1/G2; a
renderer-first sequence would make the observation surface precede the state
it is meant to report.

**Ideonomy passes / overturns:** one G4 decomposition pass using
decomposability and direction; no overturn. It added an explicit behavioral-red
step before each production slice and a separate absent-overlay compatibility
check.

**Capture:** plan committed at
docs/superpowers/plans/2026-09-10-the-vent.md. The existing root
IMPLEMENTATION_PLAN.md remains the unrelated population/Lot plan.

  generalization must cite independent duplicated rules and a measured cost.

## Task 1 — seam inventory and non-vacuous probes

**Decision:** Stage 1 projects one `WaterSubstrate` per existing marine
stratum, in ascending `Vertex` order and each column's shallowest-first order.
The terminal stratum is the seabed; shallower strata are water-column samples.
`waterworld_from(&World, &GeneratedTerrain, &GeneratedClimate,
WaterWorldConfig) -> WaterWorld` returns an empty projection when
`config.enabled` is false and otherwise reuses the passed artifacts without
rebuilding them.

**Exact live accessors:** terrain supplies
`geosphere(&self) -> &Geosphere`, `water_kind_at(&self, Vertex) -> WaterKind`,
`sea_level(&self) -> ReferenceElevation`,
`elevation_at(&self, Vertex) -> ReferenceElevation`,
`boundary_at(&self, Vertex) -> Option<VertexBoundary>`,
`has_edifice(&self, Vertex) -> bool`, and
`features(&self) -> &FeatureIndex`. Climate supplies
`biome_expr_at(&self, Vertex) -> BiomeExpr`,
`strata_at(&self, Vertex) -> Vec<Stratum>`,
`biome_expr_at_stratum(&self, Vertex, Stratum) -> Option<BiomeExpr>`,
`temperature_at(&self, Vertex, WorldTime) -> Temperature`,
`insolation(&self) -> f64`, and
`current_at(&self, Vertex) -> [f64; 3]`.

**Missing-accessor ruling:** there is no direct ocean-depth accessor, no
inverse from a marine `Stratum` to a sample depth, and `GeneratedClimate` does
not retain/expose its input `SeafloorFeature` map. Stage 1 therefore derives
seabed depth at the composition root as
`max(0, terrain.sea_level() - terrain.elevation_at(vertex))`; its named
`band_entry_depth_m` proxy uses the exact public thresholds documented by
`Stratum::at_depth_m` for nonterminal column samples; and seafloor context
comes from terrain's `boundary_at`, `has_edifice`, and feature extents. No
symmetry-only domain accessor was added. A one-pass cross-domain/tree ideonomy
check separated retained direct reads from derived inverse reads and absent
retained inputs; it produced no overturn and reinforced keeping all three
proxies explicit at the composition root. The discarded alternative was
adding climate/terrain getters solely to make the Waterworld surface look
symmetrical. Capture action: this ruling is durable here; no follow-up is
needed unless a later consumer demonstrates duplicated inverse-depth logic.

**TDD evidence:** the compiling empty projection failed behaviorally with
`substrate=0 seabed=0 column=0 depth_distinctions=0`, while its independent
live-source probe already measured 29,679 marine vertices, 29,677 nonzero
currents, 2,219 seafloor boundaries, and 29,667 terrain-feature witnesses.
After the minimal projection, seed 42 measured 83,997 substrate samples:
29,679 seabed, 54,318 open-column, and 54,318 depth distinctions. All four
`waterworld::seams` tests passed. Stage 1 consumes no randomness and therefore
earns no stream label; `streams.rs` records that absence beside the manifest.
