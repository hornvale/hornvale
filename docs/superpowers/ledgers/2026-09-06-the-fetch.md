### #1 [G1] — measure the locus before choosing the anchor

**Question.** Is The Fetch a home-to-current anchor substitution, or does the
defect sit earlier where remembered water is filtered and collapsed to one
room?

**Decision.** Treat the first design step as a measurement of three loci:
remembered-set admission, target ranking, and route execution. Do not commit to
`here` anchoring, a ranked list, or a set-returning signature until the probe
reports (a) how often home filtering removes all water reachable from the
creature's current position, (b) how often home and current ranking disagree,
and (c) which committed facts and fixtures observe each difference.

**Why (precedent cited).** The Surmise deliberately chose home anchoring and
reserved nearest-to-current as a followup. The Tidings already split hearsay
onto current position, proving that home anchoring can strand a creature. The
Culvert's current `believed_water` implementation confirms that the fold both
filters and selects from `npc.home`, while `plan_to_water` receives the real
hazards later and `shared_believed_water` only current-anchors after its inputs
have already been collapsed. The inverted `believed_hazard` twin keeps a set and
leaves geometry to the planner.

**Alternatives discarded.** Immediate home→here substitution: it changes the
reference but leaves irreversible filtering in the fold and may recreate the
unbounded position-key shape The Culvert excluded from memoization. Immediate
set-returning redesign: semantically attractive, but its public signature and
all consumers should not move before the disagreement population is known.
Immediate ranked-list redesign: preserves information but introduces an
ordering contract whose benefit is not yet measured.

**ideonomy passes / overturns: 1 / 0.** Tree-finding × substitution ×
abstraction-lift, graph × cycle; scope, visibility, distribution, naturalness,
polarity. The pass reframed the problem from “move the anchor” to “choose where
remember → propose → plan makes an actor-relative decision.” It surfaced the
three-locus measurement and the allocentric-memory / egocentric-action split;
no recommendation was overturned.

**Capture.** Next follow-up is a deterministic probe over the existing vessel
helpers and the seed-42 / seed-17 shapes. Keep all probe output in the campaign
ledger or a committed test module; do not write a spec prediction from an
unmeasured generated-output claim. Preserve the known client-check requirement
if a vessel signature changes.

### #2 [Q] — the disagreement exists in the smallest direct witness

**Question.** Do home and current anchors actually disagree on one fixed
remembered-water population, or is the stranded case only a narrative edge?

**Decision.** The disagreement is real and belongs at the admission boundary.
The committed ignored probe
`windows/vessel/src/liveness.rs::fetch_probe_compares_home_and_current_water_decisions`
uses one NPC, two remembered water rooms, `home = raddr(1.0)`, and a current
position at `raddr(-1.0)`. It reads the raw remembered set, then independently
ranks it from home and from here with the same route primitive.

**Evidence.** Focused run after formatting:

```text

test liveness::tests::fetch_probe_compares_home_and_current_water_decisions ... ok
test result: 1 passed; 0 failed; 0 ignored; 0 measured; 740 filtered out
```

The same remembered set has two rooms, but each anchor admits only one and
selects a different room. Current `believed_water` therefore cannot recover the
current-position candidate after home admission has discarded it. This is a
direct probe result, not a generated-artifact prediction.

**Why (precedent cited).** The Surmise reserved nearest-to-current as a
followup; The Tidings documented the stranded-home case; the code inspection
shows `plan_to_water` is downstream and cannot repair a `None` or a discarded
candidate.

**Alternatives discarded.** Treat the issue as ranking-only: falsified by the
1/1 admission split. Use `shared_believed_water` as the current-anchor control:
rejected because it current-ranks only the already home-admitted outputs of
`believed_water`.

**ideonomy passes / overturns: 1 / 0.** The G1 tree/substitution/lift pass was
the required disruption pass for this nontrivial measurement question; it
identified admission as irreversible and no later pass overturned that result.

**Capture.** The probe is committed beside the private helpers. The next
follow-up is to broaden it over the existing seed-42 and seed-17 shapes and
enumerate committed observers before selecting the public return shape.

## Follow-ups

- Enumerate observers of the result: `nearer_to_home`, `believed_water`, errand

### #3 [G2] — preserve the belief surface; make reachability actor-relative

**Question.** What mechanism should The Fetch take after the direct witness
showed home/current disagreement?

**Decision.** Preserve `believed_water -> Option<Facet>` and the existing
errand, affect, and save-format surfaces. Make both admission and ranking in
`believed_water` use the creature's committed current position at read time;
make `nearer_to_home` the same current-position fold so incremental and
re-derived beliefs cannot diverge. Do not thread the existing `RouteMemo`
through this path: its key is home-based, while the new key population varies
with position. Use direct current-position route searches and measure their
deterministic search count in the implementation tests.

**Approval.** Nathan approved this design boundary on 2026-09-06. The
approval covers the public shape and ownership boundary; it does not approve
artifact rebaselining or an epoch change before observed diffs are reviewed.

**Alternatives discarded.** Returning a set or ranked list would move geometry
to the planner but widen every consumer and the serialized-behavior surface;
the smaller approved change captures the demonstrated defect without that API
blast radius. Reusing `RouteMemo` would make a position-varying decision look
like a bounded home cache and is explicitly disallowed until a separate cache
key/ownership design is proven.

**Ideonomy.** passes 2, overturns 0; the two recorded passes supplied the
irreversible-filter diagnosis and the staged decision matrix. No new creative
operation was needed after approval because this ruling selects the measured
smallest boundary.

**Capture.** Draft the G3 spec and staged plan; add red-first tests for current
position admission, incremental-fold alignment, determinism/reload stability,
and observer changes before changing production code.
