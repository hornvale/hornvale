#2 [G1] — **Scope: Nathan's items 1, 2, 4, 5, 6 are FOUR campaigns, not one.**
Decision: this campaign takes **2, 4 and 6** only · Why: items 1 and 5 both
require mechanisms that do not exist — item 5 needs `MAP-one-kind-model`'s
additions two (kind-to-kind edges) and three (`Lineage`-derived per-instance),
which the frontier essay sequences deliberately and warns against bundling;
item 1 needs creatures to *choose* a rest site, which is a behaviour addition,
not a data one · **Ordering established and it is not the obvious one: choosing
(item 1) must precede preferring (item 5).** A preference is meaningless where
nothing chooses — "goblins prefer bracken" never expresses in a world where
every creature sleeps where it stands · Alternatives discarded: one large
campaign, which would bundle two additions of a three-addition arc against the
essay's explicit warning · ideonomy passes / overturns: 1 / 2 (see #3, #4) ·
Capture: the four-campaign decomposition is in the spec's §1; Nathan approved
the split and the starting point.

#3 [G1] — **OVERTURN: item 4 is not a separate item; it is item 6's first
finding.** `REST_BOUT` is a fixed quarter of a *standard* day, which makes it an
instance of the **per-world** rung of the very ladder item 6's audit exists to
enumerate. Decision: `REST_BOUT`'s conversion becomes the audit's **worked
example** rather than a parallel task, so the campaign has two deliverables
rather than three · Why this is a real simplification and not a relabelling: the
conversion and the audit share a verdict vocabulary, and doing the conversion
first without the vocabulary would mean inventing the reasoning twice ·
ideonomy: `decomposability` prompt, applied to "a constant that should be a
component" · Capture: spec §3.

#4 [G1] — **OVERTURN: the audit's output is COVERAGE, not DETECTION, and that
dissolves the population problem.** I was about to scope the sweep by file to
keep its initial population small — 610 numeric `const`s workspace-wide, 269 in
files that touch a species or a body. Wrong axis. Can you predict which
constants are wrong without reading them? The campaign's own evidence says no:
`FATIGUE_RISE` was found by **Nathan, in a design conversation**, not by any
sweep. So the tool does not need to be clever, it needs to be **total** — and
most of the 610 are trivially `universal` and declare themselves in one word.
Scope by how *contested* a rung is, not by which file a constant sits in;
blanket-declare the physics crates and spend the effort on the creature-modelling
middle where the answer is genuinely arguable. `pending(wave-N)` is already a
ratified verdict class in `tools/type-audit`, so a phased backlog has precedent
in this repo rather than needing one invented · ideonomy: `predictability`
prompt · Capture: spec §4.

#6 [G4] — **OVERTURN, caught by verifying the brief against the code before
dispatch: `ThingTraits.doc` is an `Option`, and the plan recommended the
opposite.** Measured:

```text
  concept_doc arms   16        THING_KINDS rows   17
  "hearth" glossed?  NO — it is BORROWED, ceded to settlement (decision 0025)
```

The plan said to prefer a plain `&'static str` on every row, with a borrowed
kind carrying "a real gloss that happens to be unused", on the reasoning that a
`None` would be a second encoding of `BORROWED`. The code disagrees, and the
stronger argument runs the other way: a gloss authored in `domains/thing` for
`hearth` would be **a second definition of a concept `settlement` owns** — a
divergent copy of another domain's prose, which is the precise defect class this
campaign exists to remove. A `None` is narrower and true: *this domain does not
define this concept's gloss*.

The test becomes a four-way match rather than a non-empty assertion, which is
strictly more than the original asked for — it now catches a borrowed kind that
grows a gloss, which is the direction that would actually do damage. Two
mutations, not one.

**Recorded as an overturn rather than an edit** because the plan's recommendation
was reasoned and wrong, and the thing that caught it was the mandatory
verify-the-brief-against-the-code step running one task ahead — the same step
that caught four defects in The Wicket. Cost if the ruling is wrong: a `None`
that should have been a string, visible the moment anything reads a borrowed
kind's gloss, which nothing does.
