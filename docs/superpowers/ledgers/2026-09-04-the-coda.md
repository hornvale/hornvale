### #1 [G1] — reconcile records; do not archive history

**Question:** How should the project review completed and incomplete campaign
documentation without turning its historical record into a disposable archive?

**Decision:** Run an evidence-led exception audit. Preserve specs, plans,
chronicles, retrospectives, ledgers, and decisions in place. Classify each
campaign's closure state from durable evidence; route each unresolved residue
once, to the registry only when it is an enduring speculative direction.

**Why (precedent cited):** The Frontier makes registry IDs permanent and says
that an idea draining into a spec flips status rather than being deleted.
The Cartulary establishes a committed campaign ledger as the durable home for
rulings and deferred findings. `docs_consistency.rs` already freezes the
spec-plan matcher’s blind spots and the pre-ledger exemption population; the
campaign should extend that evidence rather than infer completion from a
checkbox or filename.

**Alternatives discarded:** Broad archival/deletion would erase provenance;
adding every unfinished item to the registry would turn a speculative backlog
into an issue tracker; trusting only the exact filename matcher would preserve
the known coverage hole.

**Ideonomy passes / overturns:** 2 / 0. The first matrix pass separated
artifact lifetime from residue type. The second atlas pass made the audit’s
asymmetry explicit: a historic record may close without a registry row, while
an unresolved product direction must have one durable home.

**Capture actions:** Spec §3; the reconciliation report; this ledger.
