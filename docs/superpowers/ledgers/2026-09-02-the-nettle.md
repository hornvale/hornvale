#4 [G1] — **Item 4's cost is bimodal, and the brief's figure is the wrong
mode.**

*Measured* (this Mac, warm 36 GB `target/`, `cargo nextest run -p hornvale
--test suite -E 'test(docs_consistency)'`, 28 tests):

| condition | wall | test execution |
|---|---|---|
| after a 137-commit absorption (cli suite cold) | **234.6 s** | 2.094 s |
| immediately after, binary warm | **2.443 s** | 1.324 s |

*Why it matters.* The registry row proposed "~1 s", which is the execution
figure. The wall is the suite binary's build. A docs-only commit right after
absorbing main — a chronicle or retrospective commit at campaign close — is
exactly the moment the tree is cold, so the expensive mode is not rare.

*Decision.* Still worth it, and the arithmetic is in spec §4: one absorption
cycle costs ~234 s once plus ~2.4 s for each subsequent docs commit, against a
merge phase reddening on the canonical box after taking the shared claim
(a merge is ~1129–1595 s). The task derives the test set from what each test
**reads**, with a branch table rather than a predicted set.

*ideonomy passes / overturns.* Covered by #2's pass.

*Capture.* This entry; spec §4; the registry row updated with the real figures.
