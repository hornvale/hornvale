# The Rack Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A possession turn reads dense per-slot arrays the tick wrote —
each body's room and felt state — instead of re-folding every present
body's drives from the ledger with cold memos, and the per-turn budget
becomes a counted, deterministic test in the commit gate.

**Architecture:** `Session`'s parallel per-body vectors (`bodies`,
`roll_keys`, `on_roll`, `driven`) become one `Roster` struct of arrays in
`windows/vessel/src/roster.rs` with a single `push` and a `Slot` newtype,
plus two new columns: `position: Vec<Facet>` (a view of the ledger, pinned
VIEW ≡ SCAN) and `felt: Vec<Felt>` (content: the tick's own resolution,
decision 0596). `step_with_occupancy` returns one `Written` record per body
it walked (the `st.pos`/`st.affect`/`st.mode`/`st.suppressed` it already
holds); `wait` writes them into the slots. `snapshot`, `needs`,
`colocated_npcs`, `narrate_motion` and the presence line read the columns;
`sighting()` is derived once per turn. A `TurnWork` counter set on
`Session` (interior-mutable `Cell`s, reset per `handle`) is asserted per verb
class by a commit-tier test.

**Tech Stack:** Rust 2024, std-only plus `serde`/`serde_json`/`libm`.
`cargo nextest`; in-module tests for `roster.rs`; `tests/suite/*.rs` behind
`windows/vessel/tests/suite.rs`.

**Spec:** `docs/superpowers/specs/2026-09-02-the-rack-design.md`

**Ledger:** `docs/superpowers/ledgers/2026-09-02-the-rack.md` — append a
ruling as it is made, do not batch to the end. Decision block: 0596–0605.

## Global Constraints

- **Layering** (`cli/tests/architecture.rs`): `kernel` → `domains/*` →
  `windows/*` → `cli`. No new dependency edges are expected; if one appears,
  `book/src/reference/layering-generated.md` is a `REBASELINE=1` golden.
- **Dependencies**: `serde`, `serde_json`, `libm` only. No new crates.
- **No `HashMap`/`HashSet`** — `BTreeMap`/`BTreeSet`/`Vec` only. **No
  wall-clock** in sim or tests (`Instant` is banned; the two `move_cost`
  examples carry the scoped allow).
- **Determinism**: same seed, same script → byte-identical session goldens
  across two runs. The roster is append-only and position-stable (decision
  0546): a body's `Slot` never changes, and `narrate_motion`'s positional
  zip over the other bodies stays correct.
- **The ledger is the only stored truth**: nothing in the rack is
  serialized; `position` and `felt` are FRAME-tier like `Occupancy`
  (decision 0069).
- **VIEW ≡ SCAN for `position`**: at every read, `position[slot] ==
  agent_position(&ledger, &body, day)`. A disagreement is a writer bug.
- **`felt` is content, not a view** (spec §3.4, decision 0596): a slot holds
  the tick's own resolution; between ticks a body does not re-feel.
- **Byte-identity where the spec says so**: Stage 2 (the rack refactor and
  the tick's write-back) must NOT move a session golden; Stage 3 (the turn
  reads `felt`) DOES move `sensed.present[*].felt` wording — rebaselined
  under the decision rule, never silently.
- **Every test carries a `MUTATION THIS MUST FAIL AGAINST:` line** naming a
  compiling edit the implementer FOUND and ran, with the observed red
  (decision 0353). A plan-prescribed mutation is a starting suggestion; if
  it is a null, find one that is not and say so.
- **Ratchets that bite** (five briefs went red on them in The Roll): the
  type-audit `check` is default-deny on every pub-boundary primitive
  (`bare-ok(count: …)`, `bare-ok(index: …)`, `bare-ok(ratio: …)`,
  `bare-ok(flag: …)`); `#[ignore]` reasons need the `claim:` shape
  (decision 0093) and `cli/tests/suite/heavy_tier.rs` freezes untokenised
  reasons; `cli/tests/suite/lexicon_guard.rs` counts bare `cell` tokens —
  write "room"/"slot"/"vertex"; a new stream label touches three places
  (none expected here); the audit report regenerates in the same commit as
  a new pub boundary: `cargo run --manifest-path tools/type-audit/Cargo.toml
  -- report > docs/audits/type-audit-report.md`.
- **`cargo fmt` is the final step before every commit.** The pre-commit hook
  runs `make gate-commit` on Rust paths; never bypass; commit the
  `docs/timings.md` row separately as `chore(timings): record the-rack task
  N gate runs`. Commit messages via `git commit -F <file>` written with the
  Write tool (a bash heredoc has leaked an `EOF)` into history before).
- **Run a test binary once, then grep the log** (a hook refuses two `cargo
  test` invocations in one shell line): `cargo test -p hornvale-vessel
  --test suite > /tmp/hv.log 2>&1; grep -E "^test result|FAILED|panicked|\.\.\. FAILED" /tmp/hv.log`.
- **Push at every task boundary.** Absorb main at every stage boundary with
  `make sluice-stage BRANCH=campaign/the-rack REF=$(git rev-parse HEAD)`.
- **A new vessel test is not in the commit gate until the next green
  chamber job rewrites `docs/timings/subfloor-roster.tsv`** (its header
  says so); it runs in the stage gate from its first commit. Say this in the
  test's doc rather than claiming it gates commits today.
- Branch: `campaign/the-rack`. Worktree: `.claude/worktrees/the-rack`
  (main absorbed at `1343e7b8c` before Task 1).

```rust
/// Per-turn work counters (The Rack, spec §3.5): deterministic on every box,
/// reset by `Session::handle` for every non-empty verb line. `Cell`s because
/// the reads that do the work (`snapshot`, `needs`) are `&self`.
/// type-audit: bare-ok(count: affect_folds), bare-ok(count: position_folds), bare-ok(count: shadowcasts), bare-ok(count: plan_searches), bare-ok(count: bodies_scanned)
#[derive(Debug, Default)]
pub struct TurnWork {
    pub affect_folds: std::cell::Cell<u32>,
    pub position_folds: std::cell::Cell<u32>,
    pub shadowcasts: std::cell::Cell<u32>,
    pub plan_searches: std::cell::Cell<u64>,   // HomeNavCache::searches() at reset
    pub bodies_scanned: std::cell::Cell<u32>,
}
/// A copy of the counters as plain numbers, for a test to read after `handle`.
/// type-audit: bare-ok(count) on every field
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub struct TurnWorkRead { pub affect_folds: u32, pub position_folds: u32, pub shadowcasts: u32, pub plan_searches: u64, pub bodies_scanned: u32 }
impl TurnWork { pub fn reset(&self, searches_now: u64); pub fn read(&self, searches_now: u64) -> TurnWorkRead; }
// Session
pub fn turn_work(&self) -> TurnWorkRead;      // read AFTER a handle/snapshot
pub fn snapshot_work(&self) -> TurnWorkRead;  // reset, snapshot(), read — the test's one-call instrument
```

`plan_searches` in `read` is `searches_now - searches_at_reset`. `bodies_scanned` increments once per body iterated in `colocated_npcs`.

```rust
/// column is index-aligned by construction: `push` is the only append and it
/// pushes every column in one statement.
```
