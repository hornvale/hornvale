# The Hand — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make a creature and a possessed body one type, make possession a
selection rather than a minting, and make the source of a body's intent a
parameter of the tick.

**Architecture:** `Npc` gains the two fields `Agent` had that it lacked, both
derivable from data every construction site already holds. Both constructors
collapse onto one. `Session` then holds a single roster plus the index of the
body being driven; `Agent`, `AgentId` and the `VESSEL_AGENT` stream label are
deleted. The tick runs for every body, arbitration always, with the intent
coming from a `Controller` — GOAP by default, player input for the driven one.

**Tech Stack:** Rust 2024, `windows/vessel` (`liveness.rs`, `session.rs`,
`agent.rs`), `windows/lab` (`synthetic.rs`, `health.rs`). No new dependencies.

**Spec:** `docs/superpowers/specs/2026-08-23-the-hand-design.md` — read it
alongside this plan; the plan argues from it.

## Global Constraints

- **No `HashMap`/`HashSet`** — `BTreeMap`/`BTreeSet`/`Vec` only. Float sorting
  uses `total_cmp`. Enforced by `clippy.toml` `disallowed-types`.
- **No wall-clock time.** Time is `WorldTime { day: f64 }`.
- **No new dependencies.** The allowlist is `serde`, `serde_json`, `libm`.
- **Every crate sets `#![warn(missing_docs)]`** — every public item, field and
  variant gets a one-line doc comment.
- **Rust edition 2024**; `cargo fmt` is the final step before every commit.
- **Every primitive at a `pub` boundary carries a `type-audit:` tag.**
  Adding a `pub` item with a bare primitive moves
  `docs/audits/type-audit-report.md`; regenerate it in the same commit.
- **Integration tests** live under `<crate>/tests/suite/` and are declared in
  `<crate>/tests/suite.rs` with an explicit `#[path]`.
- **Run the suite once, capture, then grep.** Never re-run to read a second
  line: `cargo nextest run -p hornvale-vessel --no-fail-fast 2>&1 | tee /tmp/hv-hand.txt`
- **Mutations use `scripts/mutate.py`**, which refuses a substitution that is
  not found and unique. **Restore from a `/tmp` copy, never `git checkout --`**
  — that reverts your new test too and its absence reads exactly like a pass.
- **Assert the branch before every commit and push.** A cwd reset cost The Deed
  two commits on `main`:
  `git branch --show-current | grep -qx 'campaign/the-hand' || exit 1`
- **A red from a compile error proves nothing about an assertion.** Where a
  type does not exist yet, capture the behavioural red against the live surface
  first.

indistinguishable in the drift.
