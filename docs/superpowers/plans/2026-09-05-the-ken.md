# The Ken — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stop the possession surface from speaking in a frame the player character does not occupy — remove a spectral classification, a facet id and a decimal day from creature prose, delete a vacuous exits clause, and make every displayed creature noun one the parser will actually resolve.

**Architecture:** Five independent prose/resolution fixes in `domains/astronomy` and `windows/vessel`, each with its own failing test first. No new types, no new module. Two in-repo consumers outside the cargo workspace (`clients/vessel`, `clients/game` fixtures) must move in lockstep, and `gate-commit` cannot see either.

**Tech Stack:** Rust (edition 2024), `cargo nextest`, Deno (`clients/vessel`). No new dependencies — the workspace allowlist is `serde`, `serde_json`, `libm` only.

**Spec:** `docs/superpowers/specs/2026-09-05-the-ken-design.md`

## Global Constraints

- **No new crates.** The allowlist is the `ALLOWED_EXTERNAL` const in `cli/tests/suite/architecture.rs`.
- **No `HashMap`/`HashSet`**, no wall-clock time. Enforced workspace-wide by `clippy.toml`.
- **`cargo fmt` is the final step before every commit.** Fmt-gate skips are this project's most common review finding.
- **Every crate sets `#![warn(missing_docs)]`** — every new public item needs a one-line doc comment.
- **Do not touch stream labels, seed derivation, or quantization.** Nothing in this campaign is a save-format change; if a task appears to need one, STOP and report.
- **`make gate-commit` before each commit.** It does NOT scan `clients/` — Tasks 2, 3 and 6 additionally require `make vessel-check`.
- **Regenerate in the task that moves the artifact**, not at the end. Every commit stays green.
