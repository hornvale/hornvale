# The Drift Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the underworld's levels contiguous, its branches band-scoped,
and its band-to-band connections drawn with connectivity guaranteed by
construction.

**Architecture:** Delete the per-level existence coin that shatters an
already-correct shape; collapse the delve ladder's three names into one kernel
`Band`; re-key the three per-branch draws to include the band; draw
band-transition edges so that every branch descends and every branch is
reachable, by construction rather than by repair.

**Tech Stack:** Rust 2024, no new dependencies (`serde`, `serde_json`, `libm`
only — decision 0004). `cargo nextest`, `make gate-commit`, `make rebaseline`.

**Spec:** `docs/superpowers/specs/2026-08-23-the-drift-design.md` — **read
AMENDMENT A first**, then §3 (the findings) and §4 (the design) before Task 1,
and §6 (preregistration) before Task 8. Amendment A removes `entrance` from
the lattice entirely and makes this a `chamber/v4` epoch, reversing §5.

## Global Constraints

- **No `HashMap`/`HashSet`.** `BTreeMap`/`BTreeSet`/`Vec` only. Float sorting
  uses `total_cmp`. Enforced by `clippy.toml` `disallowed-types`.
- **No wall-clock time.** Time is `WorldTime { day: f64 }`.
- **Every crate sets `#![warn(missing_docs)]`** — every `pub` item, field and
  variant gets a doc comment.
- **`cargo fmt` is the final step before every commit.** fmt-gate skips are
  this project's most common review finding.
- **Never `--no-verify`.** If the hook complains, that is the finding.
- **A draw keys on a place in a fixed lattice, never a generation ordinal**
  (decision 0102).
- **Do not restate the band ceiling as `0..5`.** Derive it from the ladder.
  This family of defect was found **eight times** in The Stope, once in
  shipped code. `windows/worldgen/tests/suite/junctions.rs::habitation_bands`
  is the sanctioned helper shape.
- **Run long commands in the foreground** with an explicit `timeout:
  3600000`.

## Ruling 1 — a guarantee is asserted, not scanned

Spec §6's closing line binds every task here. §4.5's two properties
(everything descends, everything is reachable) get tests that **construct** a
case and assert, not a three-seed panel scan that finds no counterexample. A
scan over three seeds is evidence about three seeds.

## Ruling 2 — measure before and after, with the same instrument

Task 0 writes the probe against the **unmodified** tree and records today's
numbers; Task 8 re-runs it. A probe written after the change cannot tell you
the change did anything.

**"The same probe" means the same MEASUREMENT, not the same text.** Tasks 3
and 4 rename `BandKind`, `floor` and `floors_in_run` workspace-wide, and the
probe is swept with everything else. What must not change is *what is
counted*: the denominators, the one-walk-per-system rule, and the
open-mouth definition. If a rename tempts you to alter any of those, that is
the moment to stop and report — a baseline you edited is not a baseline.

## Ruling 3 — you may override this plan

Every defect in The Stope's plan text was found by checking its claims against
the tree. If a step's premise is false, say so in your report and do what is
correct. State the disagreement; do not silently deviate.

- [ ] **Step 2: Write the probe.**

Measure, per the spec's §6 definitions:

```rust
/// Per system: the share of that system's levels reachable from its OWN
/// entrances, walked ONCE from the union of open mouths.
///
/// NOT a sum of per-entrance walks. Two entrances into one system reach
/// overlapping sets, and summing them counts levels twice — The Stope's
/// witness was double-count-safe only because `passages_from` never varied
/// `entrance`, and The Drift makes entrances vary.
fn reachable_in_system(seed: Seed, terrain: &GeneratedTerrain, cell: CellId) -> (usize, usize) {
    let Some(cave) = terrain.cave_at(cell) else { return (0, 0) };
    let gradient = terrain.geothermal_gradient_at(cell);

    let mut exists = 0usize;
    for &band in &habitation_ranks() {
        for branch in 0..BRANCHES_PER_SYSTEM {
            for floor in 0..FLOORS_PER_RUN_CEILING {
                let addr = ChamberAddr { cell, entrance: 0, band, branch, floor };
                if chamber_exists(seed, &cave, gradient, addr) {
                    exists += 1;
                }
            }
        }
    }

    // ONE walk from the union of open mouths, so no level is counted twice.
    let mut seen: BTreeSet<ChamberAddr> = BTreeSet::new();
    let mut frontier: Vec<ChamberAddr> = Vec::new();
    for entrance in 0..entrance_count(seed, cell) {
        let mouth = entrance_mouth(seed, cell, entrance);
        let addr = ChamberAddr {
            cell,
            entrance,
            band: mouth.band,
            branch: mouth.branch,
            floor: mouth.floor,
        };
        // A mouth is OPEN when the level it names actually exists. That is
        // what the committed witness counts as an "open entrance", so this
        // probe and the artifact stay comparable.
        if chamber_exists(seed, &cave, gradient, addr) && seen.insert(addr) {
            frontier.push(addr);
        }
    }
    while let Some(addr) = frontier.pop() {
        for next in passages_from(seed, &cave, gradient, addr) {
            if seen.insert(next) {
                frontier.push(next);
            }
        }
    }
    (exists, seen.len())
}
```

`EntranceMouth` is a plain struct with `pub branch: u8`, `pub band: u8`,
`pub floor: u8` and no accessor methods — verified in
`windows/worldgen/src/chamber.rs`, so build the address from its fields as
above rather than looking for a getter.

```rust
#[test]
fn every_branch_has_at_least_one_descent() {

            }
        }

/// GUARANTEE 2: every branch is reachable. Nothing is orphaned.
#[test]
fn every_branch_has_at_least_one_parent() {
    let seed = Seed(42);
    for upper in 1..=BRANCHES_PER_SYSTEM {
        for lower in 1..=BRANCHES_PER_SYSTEM {
            let edges = descent_edges_for(seed, CellId(7), 0, Band::Deeps, upper, lower);
            for b in 0..lower {

                    "branch {b} of {lower} has no parent ({upper} above, {lower} below)"

            }
        }

}
```

```rust
// Every branch above draws one child below, so nothing dead-ends.
for from in 0..upper {
    let to = draw_index(seed, cell, entrance, band, from, "child", lower);
    edges.push((from, to));
}
// Every branch below draws one parent above, so nothing is orphaned.
for to in 0..lower {
    let from = draw_index(seed, cell, entrance, band, to, "parent", upper);

}
edges.sort_unstable();
edges.dedup();
```
