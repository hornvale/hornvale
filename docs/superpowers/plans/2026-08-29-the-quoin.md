# The Quoin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build five ladder rungs — `spatial-adverbial`, `temporal-adverbial`,
`verbless-clause`, `definiteness`, `existential` — in `domains/language`,
without widening the closed `Valence` taxonomy and without registering a
single concept.

**Architecture:** Each rung extends a *different* seam. Two are role
constructions in `common_role_surface`; one is a Common construction carrying
neither `Part::Copula` nor `Part::Verb`; one is a discourse structure that does
not exist yet; one is a transformation over `Valence::Locative` in the shape
`realize_common_polar_question` already has. No new `Valence` variant, ever.

**Tech Stack:** Rust 2024, `domains/language` (`clause.rs`, `grammar.rs`,
`packs.rs`), the resolver at `cli/tests/suite/sentence_corpus.rs`. No new
dependencies — the workspace allowlist is `serde`, `serde_json`, `libm` only.

**Spec:** `docs/superpowers/specs/2026-08-29-the-quoin-design.md`

## Global Constraints

Every task's requirements implicitly include all of these.

1. **`Valence` gains no variant.** Closed at five (decision 0326;
   `clause.rs`). If a rung appears to need a sixth, **STOP and report** —
   spec §2. Do not widen the enum.
2. **This campaign registers NO concept.** Registering one moves
   `cli/tests/fixtures/world-seed-42.json`, a byte-golden `make rebaseline`
   cannot write, which `gate-commit` does not test and only the sluice
   catches. Every witness substitutes an already-registered concept and
   records the substitution in a doc comment, exactly as The Rail's `OLD`
   ("stands in for the rung's own `long`") and `UNDER` ("stands in for the
   rung's own `at`") do. **The 35 registered concepts are:**
   - Act: `eat` `sleep` `die` `kill` `think` `drink` `move` `rest`
   - Celestial: `sun` `moon` `star` `night` `day`
   - Living: `tree` `person`
   - Quality: `one` `two` `many` `high` `low` `great` `little` `new` `old`
     `under` `over` `north` `south` `east` `west`
   - Social: `name` · Substance: `stone` `fire` `wind` · Terrain: `earth`
3. **No corpus file is edited.** All three are frozen. `LADDER_ENTRIES` stays
   `214`, `MERCHANT_ENTRIES` `12`, `FLOOD_WATCH_ENTRIES` `139`. Wanting to
   edit a corpus is a finding to report, not an edit to make.
4. **No token enters `IMPLEMENTED_DEMANDS` without a named backing test.**
   The module doc names one per token for all thirteen existing tokens; add
   yours in the same sentence-per-token style. A token added on optimism
   moves the score without moving the grammar, which that doc correctly calls
   *worse than no instrument*.
5. **Common-only is permitted and must be STATED.** If the tongue path gaps,
   say so in the `IMPLEMENTED_DEMANDS` doc as `epistemic-hedge` does. A
   stated gap is fine; a silent one is not.
6. **`cargo fmt` is the final step before every commit.** Skipped fmt is this
   project's most common review finding.
7. **Decision records use block 0446–0455**, reserved for this campaign.
   Never `max+1`.
8. **Docs-only commits skip `gate-commit`** — but `docs_consistency` and
   `generated_paths` read `docs/`, so a docs edit can break a Rust test with
   nothing local objecting. Registry Idea cells have a **600-char budget**
   (`registry_idea_cells_are_within_budget`).
9. **Push the branch at every task boundary.** An unpushed branch is
   invisible to the mouth, the chamber, and every peer.

**Substitution (Global Constraint 2).** Neither `guard`, `strike` nor

**Why this is not already covered.** `Part::ModifierTail` is in the
`TRANSITIVE` part list, so the *machinery* to hang an adjunct on an event

role returns `None` and renders as **nothing**. Task 0's Step 2 branch table
covers the case where this turns out to be wrong.
