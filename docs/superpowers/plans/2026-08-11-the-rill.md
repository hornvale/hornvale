# The Rill Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the drainage network space-filling and self-similar — render the
flow tree the world already computes for every land cell, then grow finer
tributaries off it — so a room can have a stream running through it.

**Architecture:** Two tiers over one keystone: *subdivide the scalar, never the
direction.* Tier 1 renders every land cell's flow line instead of only the
~6.7% above the river threshold. Tier 2 attaches branches to those rendered
polylines: a branch's **direction is inherited** from the trunk it joins, and
its **drainage is a partition** of the coarse cell's, by area — so basins
refine and cannot be rerouted, and the quantity with no canonical transfer is
never transferred. The width law is **already** scale-free (Task 1 proves it);
Tier 2's obligation is to supply counts and spacing at the *same* level.

**Task 4 was built once against a different design, measured, and falsified —
see spec §4.2.** Its keystone assumed the coarse flow could be lifted onto
rooms; cells are the icosphere's vertices and rooms its faces, so it cannot be.

**Tech Stack:** Rust 2024, `serde`/`serde_json`/`libm` only. `cargo nextest`.
No new crates.

## Global Constraints

- **No `HashMap`/`HashSet`** — `BTreeMap`/`BTreeSet`/`Vec` only (`clippy.toml`).
- **No wall-clock time**, including `std::time::Instant` in test code.
- **Float sorting uses `total_cmp`** with deterministic tie-breaks.
- **`#![warn(missing_docs)]`** — every public item, field and variant gets a
  one-line doc comment.
- **Type-audit tags on every `pub`-boundary primitive.** Ratified `bare-ok`
  classes are exactly: `ratio`, `count`, `index`, `constructor-edge`,
  `envelope`, `identifier-text`, `prose`, `artifact`, `diagnostic-value`,
  `render-internal`, `flag`. **Radians, unit-sphere positions and areas take
  `pending(wave-1: <name>)`.** Regenerate `docs/audits/type-audit-report.md` in
  the same commit whenever a `pub` boundary moves.
- **Transcendentals via `kernel/src/math.rs`**; `floor`/`sqrt` stay intrinsic.
- **Quantize at emit only** — never in the compute path.
- **All distances are angular** (radians on the unit sphere); areas are
  **steradians**. There is no planet radius; do not introduce one.
- **Never serialize a polyline index or a subdivision path** — both are
  build-order or address-derived, not contracts.
- **A new stream label is a save-format contract.** Declare it in the owning
  crate's `streams` module via `stream_labels!`; never borrow an existing one,
  never change an existing label's draw count or order.
- **`LOCALE_MICRO` keeps exactly four `next_f64()` draws in their current
  order.** Removing one silently shifts `openness` in every room of every world.
- **`cargo fmt` last.** Scope tests with `-p`; the controller runs `make gate`.
- **A crate-scoped green is not a branch-green** — the workspace enforcement
  tests (`claim_shape`, `docs_consistency`, `architecture`, the dep allowlist)
  live in `cli/` and no `-p <crate>` run reaches them. Report that in each task.

### Task 1: The width law is already scale-free — prove it and pin it

**This task's original premise was falsified by its own first implementer, and
the falsification is the deliverable.** It claimed `drainage` being an upstream
cell count made the width law scale-dependent, so discharge had to become a
drained area. It does not, because `cell_edge` already carries the conversion:
cells tile the sphere, so `N` cells have mean area `4pi/N`, and a locally
hexagonal tiling has spacing `d = sqrt(2/sqrt(3))*sqrt(A) = 1.0746*sqrt(A)`.
Measured across levels 4-7, `cell_spacing / sqrt(4pi/cell_count)` is
**1.07824 at every level**. So `a*edge*sqrt(count)` is already
`(a*1.0746)*sqrt(drained area)`.

Applying the original change would have multiplied the grid factor in twice,
rescaling every width by `sqrt(N6/N_L)` — x2 at level 5, **x1/64 at level 12** —
the exact scale error this campaign exists to remove.

So **no units change is made**. `TectonicGlobe.drainage` stays a count,
`channel_half_width` and `band_edges` keep their signatures,
`CHANNEL_WIDTH_COEFF` is not recalibrated, and `RIVER_MIN_DRAINAGE` keeps
comparing against a count (as a steradian area, `15.0` exceeds every discharge
in the world and would zero every channel). What this task ships instead is the
invariant promoted from an assumption to an asserted property, because Tier 2
rests on it.

**Files:**
- Modify: `domains/terrain/src/channel.rs` (documentation only)
- Test: `domains/terrain/tests/rill_properties.rs`

**Interfaces:**
- Consumes: `channel_half_width`, `band_edges`, `Geosphere::cell_count()`.
- Produces: **no signature change.** The deliverable is R-3's scale-invariance
  property plus the doc comment recording why no units change was needed.

### Task 2: Every run reaches its outlet

`build` stops a run **before** a non-river downhill target and then discards
runs shorter than two cells. A river cell whose downhill target is not a river
and which has no river inflow therefore becomes a one-cell run and is dropped.
Stage 1 verified the consequence as a set intersection: the 39 seed-42 river
cells carrying no polyline and the 39 reading `Dry` at their own centres are
the **same 39 cells**.

**Files:**
- Modify: `domains/terrain/src/channel.rs`
- Test: `domains/terrain/tests/rill_properties.rs`

**Interfaces:**
- Consumes: `TectonicGlobe.downhill: CellMap<Option<CellId>>` — `None` on ocean
  and at terminal sinks only.
- Produces: no signature change. `ChannelNetwork.run_cells` gains terminal
  cells; `polylines` and `band_edges` stay parallel to it.

- [ ] **Step 1: Write the failing test (R-2)**

Assert, over **at least three seeds**, that the last cell of every run is one
of exactly three things: it has no downhill target; or its downhill target is
not a river (it is the outlet the run drains into); or it was already claimed
by an earlier run (a confluence). Any run ending on a river cell whose downhill
is also a river cell is a run that stopped short.

Add a **floor**: at least 25 runs per seed and 300 across the sweep, so a
riverless world cannot pass by having nothing to check.

- [ ] **Step 2: Run to verify it fails**

Run: `cargo test -p hornvale-terrain --test rill_properties reaches_its_outlet`
Expected: FAIL — runs currently stop before their non-river target.

- [ ] **Step 3: Implement**

In `build`'s run loop, a non-river downhill target is **pushed and then
breaks**, rather than breaking before the push. The `run.len() >= 2` filter
then only excludes river cells with no downhill target at all; leave it in
place, because that case is still real.

The borrowed terminal vertex's band geometry is the one genuine decision here:
`band_edges` is computed per vertex from that vertex's drainage, slope and
spacing, and the outlet cell is not a river — an ocean cell's values would give
the mouth a nonsense width. **Use the last river cell's band geometry for the
terminal vertex.** State in your report what the alternative would have
produced, measured, not assumed.

- [ ] **Step 4: Run and report the count**

Run: `cargo test -p hornvale-terrain --test rill_properties`

Report how many runs gained a terminal vertex per seed, and confirm seed 42's
previously-uncovered river cells is now **0** (was 39). If it is not zero,
report which cells remain and why — a terminal sink is a legitimate remainder
and is R-1's known exception.

### Task 4: Tier 2 — tributaries attach to the network Tier 1 renders

**This task was built once, measured, and falsified. Read spec §4.2 before
anything else** — it records what the first attempt cost and why, and the
falsification is a campaign result you must not delete or re-derive.

The short version: cells are the icosphere's **vertices**, rooms are its
**faces**, so a `downhill` edge runs along a room's boundary and never through
it. There is no canonical lift of the coarse flow onto rooms. The first design
invented one, and it delivered **26–31%** of land to the sea where the coarse
graph delivers **74–82%**, doubled the basin count, and sent **6–7.5%** of
interior faces to a terminus outside their own coarse basin — while every one
of its local invariants passed.

The root, and the keystone that replaces it:

> **Subdivide the scalar, never the direction.** Drainage is a scalar and
> refines by **area partition** — canonical, conserving by construction,
> incapable of disagreeing with the coarse answer because the parts sum to the
> whole. Flow is a direction and needs a transfer operator with no canonical
> form. A tributary's direction is **inherited from what it is attached to**,
> so the un-transferable quantity is never transferred.

**Files:**
- Create: `domains/terrain/src/branch.rs`
- Delete: `domains/terrain/src/subdivide.rs` (see Step 1)
- Modify: `domains/terrain/src/lib.rs`, `domains/terrain/src/streams.rs`
- Test: `domains/terrain/tests/rill_properties.rs`, `tests/rill_probe.rs`

**Interfaces:**
- Consumes: `ChannelNetwork::polylines` / `band_edges` / `run_cells` (Tier 1,
  already rendered); `TectonicGlobe::drainage` / `downhill` / `water_kind`;
  `RoomAddr::corners`; `channel_half_width` and `band_edges` **unchanged**.
- Produces: your call, and state it in your report before you build. What the
  campaign needs is **more line**, queryable from a position the way
  `bank_reading` already is — not a per-room flow direction. Nothing downstream
  consumes a direction; Task 5 reads wetness.

Delete `subdivide.rs` and its `lib.rs` re-export. It has **no shipped caller**
(`flow_at`, `room_spacing`, `floor_flow`, `SubFlow` appear only in that module,
the re-export and its tests), so removal moves nothing.

**Carry these forward — they were the good half and re-deriving them is waste:**
the width law's depth pairing and its absolute anchor against

`i`; `child` digits 0/1/2 keep corners 0/1/2 and 3 is central; the outflow edge

- [ ] **Step 2: Write the composed-basin guard FIRST, and watch it on today's network**

This is the guard whose absence let the first attempt ship a falsified keystone.
**R-4:** for every branch, the coarse cell whose catchment it is a share of must
be the coarse cell its trunk chain terminates in — **≥ 99%** across ≥ 3 seeds,
with the shortfall reported rather than absorbed.

The reference is the coarse graph's **composed** answer (follow `downhill` to a
terminus), not one step of it. Three one-step invariants all passed on a network
diverging by the margins above; that is the lesson.

Write it, and **watch it pass on the current network** before you build
anything — a guard that has never been green on known-good input is not a
guard. Say in your report what it read.

- [ ] **Step 3: Write the conservation guard (R-3) before the generator**

The scalar partition is the keystone, so assert it: the drainage assigned to
the branches within a coarse cell sums to the share that cell accounts for, to
within quantization. **Conservation must be structural** — if your partition
can only be checked after the fact rather than holding by construction, say so
explicitly, because that is the difference between this design and the one it
replaces.

- [ ] **Step 4: Run to verify they fail, then build**

The properties the generator must satisfy, stated as properties because the
construction is yours to find:

1. **A branch's direction comes from its attachment.** It joins a trunk at a
   point and flows into it. Nothing computes a per-room flow direction.
2. **A branch's drainage is a share of its coarse cell's**, partitioned by area.
3. **A branch may not leave the coarse cell whose catchment it subdivides**, so
   it cannot cross a divide.
4. **The branching is driven by the partition, not a fixed ratio.** Load-bearing
   for R-5 (Step 6) — a generator that splits *k* ways by rule makes the
   bifurcation ratio an arithmetic property of *k*.

Same-level units still bind: count and spacing at the same depth, spacing from
`RoomAddr::corners()`, no `Geosphere` below cell scale (`10·4^L + 2` makes
level 12 **167,772,162**).

- [ ] **Step 5: Measure containment and channel area, both correctly**

Containment is the campaign's target — Tier 1 reached **1.237%** and the
question is what Tier 2 adds. **Do not report `is_some()`-style coverage**: the
first attempt measured 74% and it was arithmetically identical to the flow-room
fraction of land, unchanged if the subdivision were deleted. Containment means
*a polyline passes through this room*.

Channel area must use **centroid-to-centroid** reach length (two inradii,
`spacing/√3`), not the mean edge — the first attempt used the edge and
overstated the integral by exactly √3 (measured ratio 0.57739 against
`1/√3 = 0.57735`). Task 3's row-3 figure integrates true arc lengths, so a mean-edge
number is not comparable to it.

- [ ] **Step 6: R-5, with its falsification, and R-6**

**R-5:** Strahler ordering at walk depth, **geometric** mean over orders
(Horton's laws are geometric; the arithmetic mean is not their estimator and
was the sole cause of the first attempt's only reported miss). `R_b` in
**[3.0, 5.0]**, `R_l` in **[1.5, 3.5]**, ≥ 3 seeds.

**Run the falsification and report it beside the ratios:** hold your
generator's seeded freedom constant and re-measure. If the ratios do not move,
they are the rule's and not the world's, and R-5 is untestable as posed — which
is what happened last time, `R_b` landing on 4.0 to three significant figures
across three worlds because the mesh quadrisects.

**R-6:** channel area within `channel-land-fraction`'s preregistered
**[0.005%, 0.5%]**. The first attempt measured **5.4–5.9%** — ~11× the ceiling
and ~10× real continental land. **Take the branch:** inside → report it; still
breaching → a finding to ship, named as a second breach of the same
preregistered interval. **Do not retune `CHANNEL_WIDTH_COEFF`** — retuning a
constant to rescue a number after unblinding is what this project's discipline
forbids, and the controller has already recorded that the wetness improvement
is a *prediction*, not a measurement.
