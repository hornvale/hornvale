# The Plat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the underworld the residents' reading — Entry, Heart, Sanctum and landing derived from the Crosscut's plan and narrated where a people cut the place — put the first `Made` chamber in a world a player can reach by deriving chamber origins from the committed ledger at the walk, let workmanship join the plan per level so a Made rung hangs doors, and seat the energy field's creature at the plan's innermost node on whatever lies there.

**Architecture:** (1) `windows/worldgen/src/plat.rs` is a pure function over a finished `DescentPlan` — `read(&plan) -> Reading` — that adds no draw and changes no byte of the plan (spec §3.1). (2) `windows/worldgen/src/delve_seating.rs` gains `column_origins`, the ledger-side twin of `made_chambers`: `occupations_at` + `seat_at`, per column, at the walk (§3.2). (3) `plan_descent_with_origins` lets a per-level `ChamberOrigin` join the `worked` term of `cycle_budget` and the Brattice's door admissibility; `plan_descent` becomes the all-Found wrapper and is pinned byte-identical (§3.3). (4) `windows/vessel` hands `Underground::enter` the origins from `Session::delve_at`, narrates the role in a Made rung, and moves the resident mark to the Sanctum's region with the things lying there in its datum (§3.4–3.5). (5) Two audit commands build to `Full` and gain the Made population (§3.6).

**Tech Stack:** Rust 2024, std only (`serde`/`serde_json`/`libm` allowlist); `BTreeMap`/`BTreeSet`/`Vec` only; `cargo nextest`; the type-audit, placement-audit and plumb lints. No client work (nothing on the wire changes).

**Spec:** `docs/superpowers/specs/2026-09-03-the-plat-design.md` (approved at `de7905e04`; ledger `docs/superpowers/ledgers/2026-09-03-the-plat.md`, entries #1–#3 and the G3 record).

## Global Constraints

- **Layering:** `kernel → domains/* → windows/* → cli`. `hornvale_worldgen` may not depend on `hornvale_vessel`. `plat.rs` reads only `circuit::DescentPlan` — no seed, vertex, terrain or ledger reaches it (spec §3.1).
- **No new draw, no new stream label, no epoch.** `cli/src/streams.rs`'s `the_stamp_is_exactly_this_roster` must stay green untouched, and `cargo run -p hornvale -- streams` must be byte-identical before and after (Task 0 baselines it). If either moves, STOP: a draw was introduced.
- **The all-Found plan is byte-identical to today's plan.** Task 0 pins a digest over 900 plans BEFORE any grammar file is touched; Task 2 must leave that test green. The pin is the spec's §3.3 argument made mechanical.
- **Determinism:** no `HashMap`/`HashSet`; float sorts use `total_cmp`; no wall clock; every tie-break is stated (lower id, then whatever the spec says).
- **FRAME-tier (decision 0069):** nothing built here is serialized; no new fact predicate; no new thing kind (so no concept-registry accession).
- **Every crate is `#![warn(missing_docs)]`:** every pub item, field and variant gets a one-line doc. Every primitive at a pub boundary carries a `type-audit:` tag (`bare-ok(flag: landing)`, `bare-ok(count: rank)`, `bare-ok(index: level)`); `cargo run --manifest-path tools/type-audit/Cargo.toml -- check` is default-deny and in the commit gate. Any `const` of a quantity type needs a `/// plumb: <rung>(reason)` tag (`make plumb` is in the commit gate); this plan adds no such const.
- **Every seed-looping test carries a `/// claim:` tag** (decision 0093): `claim: invariant(seed: 0..N) — …`, `claim: rate(…)`, `claim: sanctioned-sweep(…)`. A test over a seeded HELPER is invisible to the scanner — tag it anyway.

Prefer `hornvale_worldgen::fixture::seed_42_world()` (a 15 ms read) plus `hornvale_worldgen::terrain_of(&world)` over a build.

- **Verify the brief against the code immediately before dispatch.** Every Brattice task found a doc comment asserting a contract the change had just altered; Task 3 names the two this plan already knows about.
- **Commit gate:** `make gate-commit` runs on every commit through `scripts/hooks/pre-commit`. Stage gates via `make sluice-stage BRANCH=campaign/the-plat REF=<full-sha>` after Tasks 2 and 4. Absorb `origin/main` locally when the mouth refuses (the conflict shape is four generated/index files: type-audit report, plumb roster, decisions-in-force, decisions README — each regenerable or a union).

```rust
/// What a node is to the people who live by the plan (spec §3.1).
#[derive(Clone, Copy, Debug, PartialEq, Eq, PartialOrd, Ord)]
pub enum Role {
    /// The shallowest node of its level — the door, and the transition
    /// between outside and the heart (Alexander 112, 127's public end).
    Entry,
    /// The center of gravity of the level's rooms: the graph median under the
    /// plan's metric, the Entry excluded (Alexander 129).
    Heart,
    /// The deepest node of its level — the most private domain (Alexander
    /// 127's private end; the hoarder's seat).
    Sanctum,
    /// Every other node; its intimacy is its own `depth`.
    Chamber,
}

/// The reading of one plan, parallel to `plan.nodes`.
/// type-audit: bare-ok(flag: landing), bare-ok(count: rank)
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Reading {
    /// Each node's role on its level.
    pub roles: Vec<Role>,
    /// True where a node is the lower end of one stair and the upper end of
    /// another — the staircase as a stage (Alexander 133).
    pub landing: Vec<bool>,
    /// The nesting depth of the node's innermost realm through
    /// `Realm.parent`; 0 for a spine node on no cycle (Alexander 98).
    pub rank: Vec<u8>,
}

/// Read a finished plan. Total and deterministic; reads nothing but `plan`.
pub fn read(plan: &DescentPlan) -> Reading {
    let n = plan.nodes.len();
    let mut roles = vec![Role::Chamber; n];
    let mut landing = vec![false; n];
    let mut rank = vec![0u8; n];

    for level in 0..plan.rungs.len() {
        let nodes = plan.nodes_on(level);
        if nodes.is_empty() {
            continue;
        }
        let depth = |i: NodeId| plan.nodes[i].depth;
        // Entry: least depth, ties to the lower id.
        let entry = nodes
            .iter()
            .copied()
            .min_by(|&a, &b| depth(a).cmp(&depth(b)).then_with(|| a.cmp(&b)))
            .expect("non-empty level");
        // Sanctum: greatest depth, ties to the lower id.
        let sanctum = nodes
            .iter()
            .copied()
            .max_by(|&a, &b| depth(a).cmp(&depth(b)).then_with(|| b.cmp(&a)))
            .expect("non-empty level");
        roles[entry] = Role::Entry;
        // A one-node level is its own Entry and Sanctum; Entry wins the
        // name because the possession stands there. The probe never saw one
        // (depth range >= 2 on every level), so this is a total-function
        // arm, not a case the world produces.
        if sanctum != entry {
            roles[sanctum] = Role::Sanctum;
        }
        // Heart: the graph median among the rest, under the plan's metric.
        let sums: BTreeMap<NodeId, u32> = nodes
            .iter()
            .filter(|&&i| i != entry)
            .map(|&i| (i, distance_sum(plan, i, &nodes)))
            .collect();
        if let Some(best) = sums.values().copied().min() {
            let degree = |i: NodeId| plan.neighbours(i).len();
            let heart = sums
                .iter()
                .filter(|(_, &s)| s == best)
                .map(|(&i, _)| i)
                .max_by(|&a, &b| {
                    degree(a)
                        .cmp(&degree(b))
                        .then_with(|| depth(b).cmp(&depth(a)))
                        .then_with(|| b.cmp(&a))
                })
                .expect("a minimum exists");
            // A level whose center of gravity is its innermost room has no
            // separate hall (spec §3.1): Heart is None there.
            if heart != sanctum {
                roles[heart] = Role::Heart;
            }
        }
        // Landing: lower end of one stair AND upper end of another.
        let lowers: Vec<NodeId> = plan.stairs_into(level).iter().map(|s| s.1).collect();
        let uppers: Vec<NodeId> = plan.stairs_from(level).iter().map(|s| s.0).collect();
        for &i in &nodes {
            landing[i] = lowers.contains(&i) && uppers.contains(&i);
        }
    }

    for (i, node) in plan.nodes.iter().enumerate() {
        let mut depth = 0u8;
        let mut cur = node.realm;
        while let Some(r) = cur {
            depth = depth.saturating_add(1);
            cur = plan.realms[r].parent;
        }
        rank[i] = depth;
    }

    Reading {
        roles,
        landing,
        rank,
    }
}

/// The nodes of `level` carrying `role`, ascending by id. One for `Entry`
/// and `Sanctum`, zero or one for `Heart`, the rest for `Chamber`.
/// type-audit: bare-ok(index: level)
pub fn role_nodes(plan: &DescentPlan, reading: &Reading, level: usize, role: Role) -> Vec<NodeId> {
    plan.nodes_on(level)
        .into_iter()
        .filter(|&i| reading.roles[i] == role)
        .collect()
}

/// Sum of shortest-path hop distances from `from` to every node in `to`,
/// with paths through the WHOLE plan (stairs included). The plan is
/// connected by construction (decision 0566), so every target is reached;
/// a target that somehow is not counts as unreachable-far (`u32::MAX / 2`)
/// rather than being dropped, so a disconnected candidate can never win.
fn distance_sum(plan: &DescentPlan, from: NodeId, to: &[NodeId]) -> u32 {
    let mut seen: BTreeMap<NodeId, u32> = BTreeMap::new();
    let mut queue = VecDeque::from([from]);
    seen.insert(from, 0);
```

```rust
/// `Made` is read from the ledger's occupation whether or not it is alive —

pub enum Tenancy {

    Wild,
    /// A seated occupation on this rung is still alive.
    Inhabited,
    /// Every occupation that seated this rung has ended.
    Abandoned,

/// The chamber origins of ONE column, per rung, read off the committed ledger
/// at the walk (spec §3.2) — the per-column twin of [`made_chambers`], which
/// reads a baked `History`. For each occupation at `vertex` whose people
/// carries an environment niche, [`seat_at`] names the rung it settled, with
/// the same three inputs `made_chambers` and the capacity probe use; that
/// rung is `Made`, `Inhabited` if any seating occupation `is_alive()`, else
/// `Abandoned`. Every other rung, and every rung of a column with no cave or
/// no occupation, is `(Found, Wild)` — the answer every column gave before
/// The Plat.
///
/// Today exactly one people carries a niche (`drow`,
/// `environment_niche_registry()`), so it is the only people that can seat
/// underground; a people with no niche is a surface people
/// (`Seating::all_surface`) and cuts nothing.
pub fn column_origins(
    world: &World,
    terrain: &GeneratedTerrain,
    vertex: Vertex,
    rungs: &[Band],
) -> Vec<(ChamberOrigin, Tenancy)> {
    let mut out = vec![(ChamberOrigin::Found, Tenancy::Wild); rungs.len()];
    let Some(cave) = terrain.cave_at(vertex) else {
        return out;
    };
    let niches = hornvale_species::environment_niche_registry();
    let gradient = terrain.geothermal_gradient_at(vertex);
    let porosity = terrain.material_at(vertex).porosity;
    let height_asl_m = terrain
        .elevation_at(vertex)
        .above(terrain.sea_level())
        .get();
    let water_table_m = water_table_depth_m(terrain.drainage_at(vertex), porosity, height_asl_m);
    for occupation in crate::history_emit::occupations_at(world, vertex) {
        let Some(niche) = niches.get(&occupation.core.people) else {
            continue;
        };
        let Some(seat) = seat_at(niche, &cave, gradient, water_table_m) else {
            continue;
        };
        let Some(i) = rungs.iter().position(|r| *r == seat.rung) else {
            continue;
        };

            (_, true) => Tenancy::Inhabited,
            (Tenancy::Inhabited, false) => Tenancy::Inhabited,
            (_, false) => Tenancy::Abandoned,
        };
        out[i] = (ChamberOrigin::Made, tenancy);
    }
    out

                }

        }
    }

}
```

```rust
//! rung a people cut, keyed by the plan's [`Role`] of the region it stands
//! in and the rung's [`Tenancy`]. Appended to `look`, never woven into it,

/// The sentence for the region the possession stands in, in a `Made` rung.
/// `None` in a wild rung, and `None` on a divider cell (a `Threshold`
/// belongs to no region — the same rule `drop` applies).
pub(crate) fn place_sentence(ug: &Underground) -> Option<String> {
    if ug.origins[ug.rung] != ChamberOrigin::Made {
        return None;
    }
    let node = crate::descent_thing::node_here(ug, ug.cell)?;
    let role = ug.reading.roles[node];
    let tenancy = ug.tenancy[ug.rung];
    let mut out = role_sentence(role, tenancy).to_string();
    if ug.reading.landing[node] {
        out.push(' ');
        out.push_str(LANDING_CLAUSE);
    }
    Some(out)
}

/// The role × tenancy table of spec §3.4, verbatim.
fn role_sentence(role: Role, tenancy: Tenancy) -> &'static str {
    let alive = tenancy == Tenancy::Inhabited;
    match (role, alive) {
        (Role::Entry, true) => {
            "This is the entry of a cut place; the rock is squared where it was worked."
        }
        (Role::Entry, false) => {
            "This was the entry of a cut place, long empty; the squared rock has dulled."
        }
        (Role::Heart, true) => {
            "This hall is the heart of the place; every way through it passes near here."
        }
        (Role::Heart, false) => {
            "This hall was the heart of a place; every way through it still passes near here."
        }
        (Role::Sanctum, true) => "This is the innermost chamber of the place.",
        (Role::Sanctum, false) => "This was the innermost chamber of a place, long empty.",
        (Role::Chamber, true) => "This is a chamber of a cut place.",
        (Role::Chamber, false) => "This is a chamber of a cut place, long empty.",
    }
}

/// The nouns [`place_sentence`] names, each answering `examine` with the
/// same sentence: `entry`, `hall`, `chamber` by role, and `stair` on a
/// landing. Empty exactly when the sentence is `None`.
pub(crate) fn place_nouns(ug: &Underground) -> Vec<crate::focalize::Noun> {
    let Some(sentence) = place_sentence(ug) else {
        return Vec::new();
    };
    let node = crate::descent_thing::node_here(ug, ug.cell).expect("a sentence implies a node");
    let word = match ug.reading.roles[node] {
        Role::Entry => "entry",
        Role::Heart => "hall",
        Role::Sanctum | Role::Chamber => "chamber",
    };
    let mut out = vec![crate::focalize::Noun::new(word, word, &sentence)
        .with_kind(crate::focalize::NounKind::Place)];
    if ug.reading.landing[node] {
        out.push(crate::focalize::Noun::new("stair", "stair", LANDING_CLAUSE));
    }
    out
}
```

```rust
/// The Heart's depth decile on `level`: `(depth(Heart) − depth(Entry)) · 10 /
/// (depth(Sanctum) − depth(Entry))`, floored; `None` where the level has no
/// Heart.
/// type-audit: bare-ok(index: level), bare-ok(count: return)
fn heart_decile(plan: &DescentPlan, reading: &crate::plat::Reading, level: usize) -> Option<u16> {
    let entry = *role_nodes(plan, reading, level, Role::Entry).first()?;
    let sanctum = *role_nodes(plan, reading, level, Role::Sanctum).first()?;
    let heart = *role_nodes(plan, reading, level, Role::Heart).first()?;
    let d = |n| plan.nodes[n].depth as u32;
    let range = d(sanctum).saturating_sub(d(entry));
    if range == 0 {
        return Some(0);
    }
    Some(((d(heart) - d(entry)) * 10 / range) as u16)
}

/// Sum of the region areas of a realm's two paths' nodes, deduplicated.
fn realm_area(plan: &DescentPlan, realm: usize) -> i64 {
    let r = &plan.realms[realm];
    let mut nodes: Vec<usize> = r.path_a.iter().chain(r.path_b.iter()).copied().collect();
    nodes.sort_unstable();
    nodes.dedup();
    nodes
        .iter()
        .map(|&n| {
            let rr = plan.region_of(n);
            rr.w as i64 * rr.h as i64
        })
        .sum()
}

/// `Needs(Key)` gates whose edge lies on `level` (either endpoint's level,
/// so a cross-floor key row's gate counts for the level it gates).
/// type-audit: bare-ok(index: level), bare-ok(count: return)
fn doors_on_level(plan: &DescentPlan, level: usize) -> usize {
    plan.edges
        .iter()
        .filter(|e| {
            let on_level = plan.nodes[e.a].level as usize == level || plan.nodes[e.b].level as usize == level;
            on_level
                && e.gate.as_ref().is_some_and(|g| {
                    matches!(g.toward_a, crate::brattice::Way::Needs(crate::brattice::Requirement::Key(_)))
                        || matches!(g.toward_b, crate::brattice::Way::Needs(crate::brattice::Requirement::Key(_)))
                })
        })
        .count()
}

/// Connected components of `level`'s within-level passage graph (§4.4).
/// type-audit: bare-ok(index: level), bare-ok(count: return)
fn within_level_components(plan: &DescentPlan, level: usize) -> usize {
    let mut unseen: std::collections::BTreeSet<usize> = plan.nodes_on(level).into_iter().collect();
    let mut count = 0usize;
    while let Some(&start) = unseen.iter().next() {
        count += 1;
        let mut stack = vec![start];
        unseen.remove(&start);
        while let Some(cur) = stack.pop() {
            for m in plan.neighbours(cur) {
                if plan.nodes[m].level as usize == level && unseen.remove(&m) {
                    stack.push(m);
                }
            }
        }
    }
    count
}
```

```rust
                || seeded_entrance_barrier(world.seed, vertex, &hornvale_worldgen::BarrierPins::default())
                    != hornvale_worldgen::BarrierState::Open
            {
                continue;
            }
            let origins = hornvale_worldgen::delve_seating::column_origins(world, &terrain, vertex, &rungs);
            let Some(made) = origins.iter().position(|o| o.0 == ChamberOrigin::Made) else {
                continue;
            };
            if want_tenancy.is_some_and(|t| origins[made].1 != t) {
                continue;
            }
            let ug = crate::underground::Underground::enter(&terrain, vertex, cave, world.seed, &origins);
            if want_door {
                let has_door = ug.plan.edges.iter().any(|e| {
                    let on = ug.plan.nodes[e.a].level as usize == made || ug.plan.nodes[e.b].level as usize == made;
                    on && e.gate.as_ref().is_some_and(|g| {
                        matches!(g.toward_a, hornvale_worldgen::brattice::Way::Needs(hornvale_worldgen::brattice::Requirement::Key(_)))
                            || matches!(g.toward_b, hornvale_worldgen::brattice::Way::Needs(hornvale_worldgen::brattice::Requirement::Key(_)))
                    })
                });
                if !has_door {
                    continue;
                }
            }
            return Some((ug, made));
        }
        None
    }

    /// Stand the possession on the first standable cell of `node`'s region.
    fn stand_in(ug: &mut crate::underground::Underground, node: usize) {
        let r = ug.plan.region_of(node);
        let level = ug.level();
        let cell = level
            .cells
            .iter()
            .filter(|(c, k)| {
                matches!(k, crate::underworld_level::LevelCellKind::Floor | crate::underworld_level::LevelCellKind::Flooded)
                    && c.0 >= r.x && c.0 < r.x + r.w && c.1 >= r.y && c.1 < r.y + r.h
            })
            .map(|(c, _)| c)
            .next()
            .expect("a region has a standable cell (ensure_standable)");
        ug.cell = cell;
    }
```
