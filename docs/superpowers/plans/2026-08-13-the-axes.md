# The Axes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Decompose `Formation` into an independently-valued axis basis, prove by
reconstruction whether that decomposition is compressive, and unify
`ConditionNiche` with `BiomeAffinity` additively — moving no world bytes.

**Architecture:** A versioned `&'static [EnvironmentAxis]` basis in
`hornvale-kernel`, sibling to the existing `v1_basis()`; a per-`Formation`
assignment in `domains/climate`; and preregistered criteria as tests that run in
the ordinary gate. Consumers keep their existing identity-based reads — the axis
interface is strictly additive (expand-contract), because prose needs identity.

**Tech Stack:** Rust 2024, std + `serde`/`serde_json`/`libm` only. `cargo
nextest`. No new crates.

**Spec:** `docs/superpowers/specs/2026-08-13-the-axes-design.md` — read it first;
this plan argues from it and does not restate its reasoning.

## Global Constraints

- **Dependencies:** `serde`, `serde_json`, `libm` only. No new crates.
- **No `HashMap`/`HashSet`** — `BTreeMap`/`BTreeSet`/`Vec` only (enforced by
  `clippy.toml` `disallowed-types`).
- **No wall-clock time.** No `std::time::Instant`, including in test code.
- **`#![warn(missing_docs)]`** in every crate: every `pub` item, field and
  variant gets a doc comment.
- **Layering:** `kernel` → `domains/*` → `windows/*` → `cli`. A domain may
  depend on `hornvale-kernel` and **nothing else**. Anything reading two
  domains lives in `windows/worldgen` (the composition root).
- **`cargo fmt` is the final step before every commit.** fmt-gate skips are
  this project's most common review finding.
- **Corpus size is 74** — 21 `Formation`s, 53 `Variant`s. Every compression
  bound derives from this number and from nothing measured later.
- **World-side measurement is deferred** pending The Glasshouse (spec §5.5).
  No task here queries real cells. If you find yourself building a world, stop
  and re-read §5.5.

/// deliberately not homogeneous, and a consumer must not assume otherwise.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]

    /// Ranked categories with a meaningful order (open ground → closed canopy).
    Ordinal,
    /// A continuous magnitude, normalised to `[0, 1]`.
    Scalar,
    /// Unordered categories; the numeric value is an index, never a magnitude.
    Nominal,
    /// A frequency, not a state. See the note on `DISTURBANCE`.
    Rate,
}

/// [`EnvironmentVector`] can carry a value on.

    /// Stable numeric id — the key an [`EnvironmentVector`] stores this axis's
    /// value under, and a save-format contract once this basis ships.
    pub id: u16,
    /// Human-readable label for diagnostics and the almanac.
    pub label: &'static str,

/// assignment are expected to be phases rather than communities.

    id: 5,
    label: "disturbance",
    valence: AxisValence::Rate,

///
/// **Append-only.** Order carries meaning: any argmax or dominant-axis read
/// resolves a total tie by basis position, so inserting an axis at or before an
/// existing one silently changes which axis wins those ties. A new axis takes
/// the next free id at the END; a change to the sequence is a `v2` basis, never
/// an edit in place. Pinned by `the_environment_basis_ids_are_append_only`,
/// which is what makes this a rule rather than a hope.
pub fn environment_v1_basis() -> &'static [EnvironmentAxis] {
    &[PHYSIOGNOMY, ENERGY, WATER, SUBSTRATE, LIGHT, DISTURBANCE]
}

```rust
/// A sparse environment vector: axis id to value. The zero vector (no axes) is
/// legal and means "unassigned," which is how a name that resists assignment is
/// represented rather than by an error.
#[derive(Debug, Clone, PartialEq)]
pub struct EnvironmentVector(BTreeMap<u16, f64>);

impl EnvironmentVector {
    /// Validating constructor: rejects any non-finite value, and any value
    /// outside `[0, 1]`. An empty slice is legal and produces the zero vector.
    /// Repeated axis ids overwrite rather than combine (last write wins).
    /// type-audit: bare-ok(constructor-edge: values)
    pub fn new(values: &[(EnvironmentAxis, f64)]) -> Result<Self, UnitError> {
        let mut map = BTreeMap::new();
        for (axis, value) in values {
            if !value.is_finite() || *value < 0.0 || *value > 1.0 {
                return Err(UnitError {
                    unit: "environment axis value",
                    value: *value,
                    reason: "must be finite and within [0, 1]",
                });
            }
            map.insert(axis.id, *value);
        }
        Ok(Self(map))
    }

    /// This vector's value on `axis`, or `None` if unassigned.
    /// type-audit: bare-ok(ratio: return)
    pub fn get(&self, axis: EnvironmentAxis) -> Option<f64> {
        self.0.get(&axis.id).copied()
    }

    /// The axis ids carrying a value, ascending.
    /// type-audit: bare-ok(index: return)
    pub fn axis_ids(&self) -> Vec<u16> {
        self.0.keys().copied().collect()
    }
}
```

//! The Axes — preregistered criteria, frozen before the fit (spec §6).
//!
//! These bounds derive from CORPUS SIZE (74 names: 21 formations, 53 variants),
//! which was known before any assignment existed. They do not derive from the
//! fit's outcome, which is what makes them auditable as un-tuned.

use hornvale_climate::axes::{assignment, AssignedName};
use hornvale_kernel::environment_v1_basis;
use std::collections::{BTreeMap, BTreeSet};

/// Distinct values actually used on each axis, measured from the assignment
/// rather than declared — a declared cardinality could be set low to pass.
fn realised_cardinalities() -> BTreeMap<u16, usize> {
    let mut seen: BTreeMap<u16, BTreeSet<u64>> = BTreeMap::new();
    for AssignedName { vector, .. } in assignment() {
        for axis in environment_v1_basis() {
            if let Some(v) = vector.get(*axis) {
                seen.entry(axis.id).or_default().insert(v.to_bits());
            }
        }
    }
    seen.into_iter().map(|(k, v)| (k, v.len())).collect()
}

#[test]
fn p1_the_decomposition_is_compressive() {
    let card = realised_cardinalities();
    let sum: usize = card.values().sum();
    let product: u128 = card.values().map(|c| *c as u128).product();

    // COVERAGE: >= 74 is necessary to distinguish the corpus at all; 500 is
    // ~7x headroom, so the space is generative rather than exactly-enumerating.
    assert!(
        product >= 500,
        "coverage: axis cardinality product {product} < 500 (cardinalities {card:?})"
    );
    // COMPRESSION: the enum costs 74 symbols; 30 is under 41% of that. This is
    // the ceiling §7 lacked — without it, one axis with 21 values passes.
    assert!(
        sum <= 30,
        "compression: axis cardinality sum {sum} > 30 (cardinalities {card:?})"
    );
}

#[test]
fn p1_no_two_names_share_a_vector() {
    let mut by_vector: BTreeMap<Vec<(u16, u64)>, Vec<&'static str>> = BTreeMap::new();
    for AssignedName { name, vector } in assignment() {
        if vector.axis_ids().is_empty() {
            continue; // a resister; p2 owns those
        }
        let key: Vec<(u16, u64)> = environment_v1_basis()
            .iter()
            .filter_map(|a| vector.get(*a).map(|v| (a.id, v.to_bits())))
            .collect();
        by_vector.entry(key).or_default().push(name);
    }
    let collisions: Vec<_> = by_vector.values().filter(|n| n.len() > 1).collect();
    assert!(
        collisions.is_empty(),
        "distinct names collided on one vector: {collisions:?}"
    );
}
```

//! The environment-axis assignment for this domain's named communities.
//!
//! **This is a DERIVATION, not a roster** (decision 0094): the kernel owns the
//! axis vocabulary; what a formation means on those axes is climate's own.
//!
//! A name with an empty vector is a *resister* — a name the axes cannot place,
//! which is a recorded finding rather than an error (spec §6.2).

use hornvale_kernel::{
    EnvironmentVector, DISTURBANCE, ENERGY, LIGHT, PHYSIOGNOMY, SUBSTRATE, WATER,
};
use std::sync::OnceLock;

/// One corpus name and the vector assigned to it.
#[derive(Debug, Clone, PartialEq)]
pub struct AssignedName {
    /// The name's registry spelling.
    pub name: &'static str,
    /// Its position in the basis; empty means it resisted assignment.
    pub vector: EnvironmentVector,
}

fn build() -> Vec<AssignedName> {
    let v = |vals: &[(hornvale_kernel::EnvironmentAxis, f64)]| {
        EnvironmentVector::new(vals).expect("authored axis values are in [0, 1]")
    };
    vec![AssignedName {
        name: "tundra",
        vector: v(&[
            (PHYSIOGNOMY, 0.20),
            (ENERGY, 0.15),
            (WATER, 0.30),
            (SUBSTRATE, 0.00),
            (LIGHT, 0.85),
        ]),
    }]
}

/// The full assignment over this domain's corpus.
pub fn assignment() -> &'static [AssignedName] {
    static A: OnceLock<Vec<AssignedName>> = OnceLock::new();
    A.get_or_init(build)
}
```

use hornvale_climate::axes::assignment;

- [ ] **Step 1: Write the measurement**

```rust
//! P-4 (spec §6.4): the affinity ladder is a hand-authored METRIC on the biome
//! space — one band out ~ 0.70, two bands out (or one step of FORM) ~ 0.45. If
//! the axes are right, that band structure should be recoverable as distance in
//! axis space.
//!
//! This reports a correlation; it is not a pass/fail gate. A weak result means
//! either the axes or the ladder is wrong, and the campaign says which it
//! concludes and why (spec §6.4) rather than quietly dropping the check.

use hornvale_climate::axes::assignment;
use hornvale_kernel::environment_v1_basis;

fn axis_distance(a: &str, b: &str) -> Option<f64> {
    let find = |n: &str| assignment().iter().find(|x| x.name == n);
    let (x, y) = (find(a)?, find(b)?);
    let mut sum = 0.0;
    for axis in environment_v1_basis() {
        if let (Some(p), Some(q)) = (x.vector.get(*axis), y.vector.get(*axis)) {
            sum += (p - q) * (p - q);
        }
    }
    // `sum.sqrt()`, not `kernel::math::sqrt` — `math.rs` carries the eleven
    // transcendentals that route through libm (decision 0041), and `sqrt` is
    // deliberately NOT one of them: IEEE-754 guarantees it exactly, so it stays
    // the intrinsic (`kernel/CLAUDE.md`).
    Some(sum.sqrt())
}

#[test]
fn axis_distance_orders_the_affinity_ladder() {
    let mut rows: Vec<(f64, f64)> = Vec::new(); // (affinity factor, axis distance)
    for (_kind, affinity) in hornvale_species::biome_affinity_registry().iter() {
        for (biome_name, factor) in &affinity.by_biome {
            for (other_name, other_factor) in &affinity.by_biome {
                if biome_name == other_name {
                    continue;
                }
                if let Some(d) = axis_distance(biome_name, other_name) {
                    rows.push((factor - other_factor, d));
                }
            }
        }
    }
    assert!(
        !rows.is_empty(),
        "VACUOUS: no biome name in the affinity registry matched an assigned \
         name. The two corpora use different spellings — reconcile before \
         reading this result as evidence of anything."
    );
    let agree = rows
        .iter()
        .filter(|(df, d)| (*df < 0.0) == (*d > 0.0))
        .count();
    println!(
        "P-4: {agree}/{} pairs agree in sign (higher affinity = nearer in axis space)",
        rows.len()
    );
}
```
