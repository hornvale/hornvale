# The Pawl Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give `kernel/src/fold.rs`'s `LedgerFold` its first tenants — a session-owned, per-entity resident store in `windows/vessel` — so no production read in `liveness.rs` walks an agent's committed `agent-at` trail per evaluation, byte-identically.

**Architecture:** One `ResidentFolds` value (new module `windows/vessel/src/resident.rs`) holds one `Folded<S>` per tenant; each tenant's state is keyed by `EntityId` internally, so a whole tenant advances in O(new facts) per read and a per-entity read is a map lookup. The seam is at READ: every read calls `advance_to(ledger)` first (idempotent in position), so the walk's two evaluations per `wait` and the `&self` snapshot all share one store. This tick's own emitted facts are passed to a read as an overlay slice, exactly as `decide_step` does today. Past-instant reads (the hazard fold's `emitter_arousal` → `affect_of(m, day)`) are served from the last reset at or before the instant, over the resident trail's range.

**Tech Stack:** Rust 2024, `hornvale_kernel::fold::{Folded, LedgerFold}`, `BTreeMap`/`BTreeSet`/`Vec` only, `std::cell::RefCell` (precedent: `kernel/src/room.rs`, `liveness.rs`). No new crates.

**Spec:** `docs/superpowers/specs/2026-09-01-the-pawl-design.md` — read §2, §3, §5 before any task. **Ledger:** `docs/superpowers/ledgers/2026-09-01-the-pawl.md` — every rule executed and every deviation goes there, in the task's own section, as it happens.

**Decision block:** 0536–0545.

## Global Constraints

- **Byte-identical.** No new fact, predicate, stream label or epoch. Do not touch the `MoveTo` arm that pushes `agent_at_fact(...)`, nor `kernel/src/ledger.rs`. The ledger-hash witness (Task 1) must stay green through every task.
- **No serialized surface.** `ResidentFolds` has no `Serialize`/`Deserialize` and is not reachable from `World`.
- **Absorb is pure in `(self, fact)`.** No terrain, no clock, no batch-size dependence inside `LedgerFold::absorb`. Anything needing `terrain` happens at read time.
- **Every tenant owes FOLD ≡ SCAN through `absorb_at`**, compared against the *existing* scan function — never against `Folded::rebuild` (Tailrace §11, item 1).
- **Both chaos schedules** (discard and rebuild the store every position; every third position) pinned per tenant.
- **Line numbers rot; grep function names.** `liveness.rs` is ~16,200 lines. Every location below is a function name.
- **Spec rules 1–6 (§3) are branch tables.** Execute the witness, record the branch taken in the ledger, then act. Never assume the branch.
- **`cargo fmt` last; `type-audit:` tag on every new `pub` primitive** (`tools/type-audit/src/tag.rs` lists the eleven classes); regenerate `docs/audits/type-audit-report.md` in the same commit as any `pub` change.
- **Every commit passes `make gate-commit`** (the pre-commit hook runs it). A test that hangs is a test reading stdin — never write one.
- **Commits end with** `Claude-Session: https://claude.ai/code/session_01VZbMTxSHFDJLtmyAUVztbc`.

/// One entity's committed `agent-at` trail, in the order `agent_sightings`
/// sorted it: by `(day, room)` ascending. Absorbed once per fact, never
/// rebuilt. A resident permutation index (spec §2.4, decision 0538).

    by_entity: BTreeMap<EntityId, Vec<(WorldTime, Facet)>>,
}
impl Trail {

    pub fn of(&self, entity: EntityId) -> &[(WorldTime, Facet)];
    /// Index of the first entry with day > `t` — the `<= t` prefix length.
    /// type-audit: bare-ok(index: return)
    pub fn prefix_len(&self, entity: EntityId, t: WorldTime) -> usize;
}
impl LedgerFold for Trail { fn empty() -> Self; fn absorb(&mut self, fact: &Fact); }

/// The session-owned store. One `Folded` per tenant; advance-on-read.

    /// Every tenant's position — the witness a test uses to prove idempotence.
    /// type-audit: bare-ok(count: return)
    pub fn position(&self) -> u64;
