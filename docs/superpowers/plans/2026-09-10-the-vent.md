# The Vent Implementation Plan

> For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Add a small deterministic Waterworld overlay measuring whether
seabed, water-column, vent, current, light, pressure, temperature, salinity,
and chemistry inputs independently reach bounded stocks, movement, and
observation outputs.

**Architecture:** Keep cross-domain composition in windows/worldgen. Reuse
already-built terrain and climate artifacts through direct typed inputs, then
derive compact substrate, ambient fields, aggregate stocks, sparse propagation,
and pure observation lenses. Add no biome variants, save facts, build rung,
domain dependency, full fluid solver, dense time cache, individual organism,
or universal habitat wrapper.

**Tech Stack:** Rust workspace; hornvale-worldgen; hornvale-kernel,
hornvale-terrain, and hornvale-climate; Seed, Stream, StreamLabel, VertexMap,
NearestVertexIndex, WorldTime; consolidated worldgen integration tests.

**Spec:** docs/superpowers/specs/2026-09-10-the-vent-design.md

## Global Constraints

- Preserve terrain, climate, marine BiomeExpr, water-column, Skyworld, and
  absent-overlay behavior.
- Keep composition in windows/worldgen; domains do not depend on siblings.
- Use existing worldly nouns. Stocks and flows is reasoning vocabulary only.
- New draws use independently named versioned streams and fixed consumption
  order; never insert conditional draws into an existing sequential stream.
- Same seed, pins, and configuration produce byte-identical state and views.
- Queries and rendering do not draw, mutate, resculpt, or rebuild inputs.
- Use ordered vectors and explicit tie-breaking; no HashMap or HashSet.
- Counters increment at actual loops and remain test-only.
- Every perturbation proves the actual hooked source changed first.
- No census, save fact, BuildDepth rung, species, metabolism, reproduction, or
  full 3D fluid simulation.
