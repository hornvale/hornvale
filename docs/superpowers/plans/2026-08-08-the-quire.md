# The Quire Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `clients/game/`, a native character-grid client you can walk a
Hornvale world in, rendering only what `vessel/session/v1` emits — plus the two
sim-side changes that make possession cheap and selectable.

**Architecture:** The client *drives across the linker* (links `hornvale-vessel`,
calls `Session::start`/`Session::handle`) and *reads across the serializer*
(every displayed datum comes from `snapshot_json`). Containment is structural: a
`hornvale-game-core` crate with **no** hornvale dependency parses its own mirror
of the schema into a cell grid; a `hornvale-game` binary links vessel and owns
the terminal. Spec:
[`2026-08-08-the-quire-design.md`](../specs/2026-08-08-the-quire-design.md).

**Tech Stack:** Rust edition 2024, `crossterm` (client only), `serde`/
`serde_json`. Outside the cargo workspace, own standalone workspace, like
`clients/vessel/wasm`.

## Global Constraints

- **`clients/` is outside the cargo workspace and outside determinism** (decision
  0055). The `serde`/`serde_json`/`libm` allowlist, `#![warn(missing_docs)]` and
  the `BTreeMap`-only ban do **not** bind `clients/game/`. Follow them anyway
  where free; `crossterm` is legal here and would not be in the workspace.
- **Anything under `windows/` IS bound** by all of the above. Tasks 1–3 touch
  `windows/vessel` and must obey the workspace rules exactly.
- **Stream consumption order is a save-format contract.** If any task changes
  which seed draws are taken, or their order, **stop and escalate** — that is a
  `vessel/agent/v2` epoch event, not a refactor.
- **Byte-identity is the success criterion for Tasks 1 and 3**, evidenced by
  `git diff --exit-code`, not by a green test suite.
- Rust edition 2024. `cargo fmt` is the final step before every commit.
- Every commit must compile and pass the checks named in its task.
- The visual floor is **monochrome at 80×24**. No colour ships in this campaign.
- Weight assignment is fixed by the brief and is not a design choice:
  `here` → Bold, `sensed` → Normal, `remembered` → Dim, never-known → **cell not
  written at all**.
- A mark's `salience` is a **rank, not a magnitude**. It may order marks; it may
  never become a weight.

## Task 1: Hoist the world-scoped derivation out of `Session::start`

**Why:** measured, `Session::start` costs **0.73 s** on an already-built world
(median of 5, quiet box). Every one of the things it derives — terrain, climate,
`LocaleContext`, the coexistence-stack fit, the demography report — is
world-scoped, not agent-scoped. Nathan's requirement that possession and release
cost nothing is this refactor.

**Files:**
- Modify: `windows/vessel/src/session.rs` (`Session::start`, from the "ONE
  derivation block (The Weir, Stage 2)" comment down to the `mint_flagship` call)
- Modify: `windows/vessel/src/lib.rs` (re-export)
- Test: `windows/vessel/tests/world_context.rs` (create)

**Interfaces:**
- Produces: `WorldContext<'w>` with `WorldContext::build(world: &'w World) ->
  Result<WorldContext<'w>, VesselError>` and `Session::start_in(ctx:
  &'w WorldContext<'w>, opts: &PossessOpts) -> Result<(Session<'w>, String),
  VesselError>`.
- `Session::start(world, opts)` is **retained** as a thin wrapper that builds a
  `WorldContext` and calls `start_in`. Every existing caller keeps compiling.

```rust
/// openings and snapshots to two sessions each started from scratch.

    let world = world();
    let opts = PossessOpts::default();

    let (mut a, open_a) = Session::start(&world, &opts).unwrap();
    let snap_a = hornvale_vessel::snapshot_json(&a.snapshot().unwrap());

    let (mut b, open_b) = Session::start_in(&ctx, &opts).unwrap();
    let snap_b = hornvale_vessel::snapshot_json(&b.snapshot().unwrap());
    let (mut c, open_c) = Session::start_in(&ctx, &opts).unwrap();
    let snap_c = hornvale_vessel::snapshot_json(&c.snapshot().unwrap());

    assert_eq!(open_a, open_b, "start_in must match start");
    assert_eq!(open_b, open_c, "a reused context must not drift");
    assert_eq!(snap_a, snap_b, "start_in must match start");
    assert_eq!(snap_b, snap_c, "a reused context must not drift");

    // must not alias session state.
```

```rust
/// The world's first settlement by its own derivation ordering — population
/// descending, then id ascending. Deliberately the SAME ordering
/// `ordered_for_derivation` uses, so possession introduces no new seed
/// ordering surface.
pub fn most_populous_settlement(
    world: &World,
) -> Option<hornvale_settlement::VillageInfo> {
    let mut all = hornvale_settlement::all_settlements(world);
    all.sort_by(|a, b| b.population.cmp(&a.population).then(a.id.cmp(&b.id)));
    all.into_iter().next()
}
```

```rust
//! The cell buffer: the one artifact every backend renders and no backend
//! owns.

/// How much a thing commands the character's notice right now.
///
/// The brief's most important channel, because it is the only one surviving
/// monochrome, a 16-colour terminal and colour-blindness intact. Note it runs
/// OPPOSITE to durability: `here` lasts one turn and is Bold, `remembered`
/// lasts forever and is Dim. Bold means perishable, not important.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
pub enum Weight {
    /// Drawn from memory: lighter stroke.
    Dim,
    /// Inked, confident, present tense.
    #[default]
    Normal,
    /// Fresh ink; the most present thing on the page.
    Bold,
}

/// What a thing IS. Monochrome for this campaign; colour is deferred.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
pub enum Ink {
    /// The default ink.
    #[default]
    Plain,
}

/// One character cell. A tile is a drop-in replacement for exactly one of
/// these: same box, same metrics, same position (the brief's cell law).
#[derive(Debug, Clone, Copy, PartialEq)]
pub struct Cell {
    /// The character drawn, or `None` for unmarked paper.
    pub glyph: Option<char>,
    /// Attention.
    pub weight: Weight,
    /// Substance.
    pub ink: Ink,
}

impl Default for Cell {
    fn default() -> Self {
        Cell { glyph: None, weight: Weight::Normal, ink: Ink::Plain }
    }
}

impl Cell {
    /// A drawn cell.
    pub fn glyph(glyph: char, weight: Weight) -> Cell {
        Cell { glyph: Some(glyph), weight, ink: Ink::Plain }
    }

    /// Unmarked paper — never known, never drawn. Not a space, and not black.
    pub fn is_blank(&self) -> bool {
        self.glyph.is_none()
    }
}

/// A dense character grid. `Vec`, not a map — dense-index storage, matching
/// the kernel's discipline even though this tree is not bound by it.
#[derive(Debug, Clone)]
pub struct Grid {
    width: u16,
    height: u16,
    cells: Vec<Cell>,
}
```

`height`, `to_plain_text` (blank → `' '`, newline-separated rows, no trailing
