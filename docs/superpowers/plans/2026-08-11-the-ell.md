# The Ell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the ledger's time axis mean one thing — standard days — and make a unit mismatch unrepresentable rather than merely documented.

**Architecture:** `WorldTime` gains a private field behind a validating constructor and becomes the type `Fact.day` carries. The history bake keeps reasoning in years and converts at its emit boundary, the same discipline `quantize` follows. `founder_handle` is rewired onto `founding_key_from`'s existing material-fold, riding the epoch the first two changes already pay for.

**Tech Stack:** Rust 2024, `serde`/`serde_json`/`libm` only (decision 0004). No new crates, no dimensional-analysis library.

## Global Constraints

- Dependencies: `serde`, `serde_json`, `libm` **only**. No new crates.
- No `HashMap`/`HashSet` — `BTreeMap`/`BTreeSet`/`Vec` only (`clippy.toml` `disallowed-types`).
- No wall-clock time. No `std::time::Instant`, including in test code.
- Every crate sets `#![warn(missing_docs)]`; every public item, field and variant gets a one-line doc comment.
- Primitives at a `pub` boundary carry a `type-audit:` verdict tag **on the struct's own doc comment**, never per field.
- `cargo fmt` as the final step before every commit.
- **Every commit must compile and pass the whole suite.** The pre-commit hook runs `make quick` **workspace-wide**, so a signature change and its call sites **cannot** be separate commits. Tasks here are sized around that.
- **`cli/tests/id_shift_invariance.rs` and `cli/tests/id_stability_under_insertion.rs` must stay green.** Task 4 is the only task permitted to touch the first, and only its expected-value comments.
- `clients/` is outside the cargo workspace; `make gate` cannot see it. `make game-check` and `make vessel-check` are required wherever an emitted artifact could move.

- [ ] **Step 2: Rewrite the struct**

Replace `kernel/src/field.rs:22-26`:

```rust
/// Simulated time in fractional days since world genesis. There is no
/// wall-clock time anywhere in Hornvale.
///
/// The field is private and the constructor validates, because this type's
/// whole job is that a value in some *other* unit cannot be stored here.
/// A year stamped into a day-typed slot is what made `person-died`
/// uncommittable in every world (The Ell); decision 0014 declined this
/// wrapper on the grounds it bought no safety, and 0125 supersedes it.
///
/// **Negative is legal.** A day is a *point on an axis*, not a duration:
/// a founder born before the history record begins has a negative birth
/// day. Do not copy `Years`'s non-negative rule here.
/// type-audit: bare-ok(constructor-edge: new), bare-ok(count: day)
#[derive(Clone, Copy, Debug, PartialEq, PartialOrd, Serialize, Deserialize)]
#[serde(transparent)]
pub struct WorldTime {
    day: f64,
}

impl WorldTime {
    /// World genesis — day zero.
    pub const GENESIS: WorldTime = WorldTime { day: 0.0 };

    /// Validating constructor: rejects only non-finite values. Negative days
    /// are legal and deliberate (see the type's doc).
    /// type-audit: bare-ok(constructor-edge: day)
    pub fn new(day: f64) -> Result<WorldTime, crate::units::UnitError> {
        if !day.is_finite() {
            return Err(crate::units::UnitError {
                unit: "days",
                value: day,
                reason: "must be finite",
            });
        }
        Ok(WorldTime { day })
    }

    /// Fractional days since world genesis.
    /// type-audit: bare-ok(count: return)
    pub fn day(self) -> f64 {
        self.day
    }
}
```

**`#[serde(transparent)]` is load-bearing and not decoration.** Without it the derive emits `{"day": 1234.5}` where the save format has a bare `1234.5`, which would be a far larger format change than this campaign sanctions. Verify `UnitError`'s field names against `kernel/src/units.rs` before using them — construct it the way that file does, not the way this snippet guesses.

**Prefer `GENESIS` to `new(0.0).expect(...)`** wherever the literal is zero — it is most of the 445, and it reads better than an expect that can never fire.
