# The Stope Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The underworld gains floors, branches, characters and engine selection — so a cave system is a place with a shape and an identity rather than five interior-less points in a column.

**Architecture:** Three seams, not a rewrite. `ChamberAddr` gains a `floor` rung and `slot` becomes `branch` (an epoch: the address *is* the seed-derivation key). The existing engine already takes a **slice** of rungs and returns `Vec<Level>`, so a "run of floors" is many entries where there is currently one. A **character** owned by a branch then selects which engine builds each run, making coherence structural — an engine cannot reach across a branch boundary.

**Tech Stack:** Rust 2024, `serde`/`serde_json`/`libm` only. `cargo nextest`. No new crates.

**Spec:** `docs/superpowers/specs/2026-08-20-the-stope-design.md` — **read §A (the amendment) first.** It corrects three premises in §3, all in the direction of less work.

## Global Constraints

- **READ SPEC AMENDMENT B FIRST.** Task 0 falsified §3.1's rarity prediction, a sixth rung was measured and refused, `Sunless` is renamed `Nadir`, and a per-branch **barrier** replaces "the eldritch is Sunless". Amendment B is Nathan's ruling and governs over §3 wherever they differ.
- **This is an EPOCH.** `chamber_key` formats the address into the seed-derivation label, so changing the address relocates every chamber in every world. The label goes to **`chamber/v3`** — `chamber/v2` is already taken (The Underworld), `chamber/v1` is retired, and neither may be reused. **An epoch suffix, never a rename.**
- **A drawn quantity keys on a place in a fixed lattice, never a generation ordinal** (decision 0102).
- **Junctions are DERIVED, never drawn.** A random link would be a new draw on top of an epoch, and would make a shortcut a die roll rather than a fact about the geology.
- **The deepest band is `Nadir`** (renamed from `Sunless`, spec B.3, landed in Task 1). **Spec B.6 LIFTED the "nothing named" clause** — the barrier's four states are named. What still stands: `thaumic` stays 0.0 (it is a *rock* axis, `domains/terrain/src/lithology.rs:105`, pinned by `buffer_axes_are_bounded_and_thaumic_is_zero`), UNI-2 stays unratified, and **barrier EFFECTS are a later campaign** — this one ships the dial, not the noise it makes.
- **No room-grain address underground.** A floor is a point plus an engine. `RoomAddr` stays a surface construct.
- **No intra-floor consistency guarantee, no vertical alignment.** Nathan's ruling. A staircase need not land anywhere in particular on the level below.
- **No `HashMap`/`HashSet`**; `total_cmp` with deterministic tie-breaks; no `Instant`.
- `cargo fmt`, then `make gate-commit` (`timeout: 3600000`) before every commit.
- Integration tests live behind `tests/suite.rs`: a new file goes in `tests/suite/` with `#[path = "suite/<stem>.rs"] mod <stem>;` **alphabetically**. A plain `mod x;` will not resolve.
- Capture long output to a file and grep it; a guard refuses two test invocations in one command. Whole-workspace runs need `HV_TEST_OK=1` and are measurements, never gates.

### Ruling 1 — real assertions

Every `#[test]` sketched here must carry assertions expressing what its comment describes. A test that compiles with no assertion is a task failure. If a test as specified cannot assert what it claims, say so and propose one that can.

### Ruling 2 — mutations

Prove a check can fail with `python3 scripts/mutate.py`, never `sed`. **This plan never prescribes which expression to mutate** — it names the property the mutation must demonstrate.

### Ruling 3 — heavy probes are `#[ignore]`d

Use `--run-ignored all` and **assert the count is what you expect, not zero.** The naive invocation runs nothing and prints what reads as success.

### Ruling 4 — the witnesses will fire, and must not be silenced

The Underworld's drow-seating readouts and every chamber-addressed test read addresses this epoch relocates. **They are expected to fire.** Re-derive and re-pin each with its new value; never delete an assertion or loosen a bound to make one pass. If a witness's *verdict* changes rather than its number, stop and report — that is a finding, not a re-pin.

### Task 3b: The descent is a sequence

**Read spec amendment C.4.** This lands **before Task 4**, which builds descents out of runs and must inherit the corrected rule rather than the accident.

**What is wrong today.** `passages_from` joins floor *N* of band *k* to floor *N* of band *k±1*. Nobody designed that; it is what the function did when a band held one interior-less point, where it was correct by vacuity. Task 2's draw made it actively wrong — measured, by running it:

```
PROBE Deeps->Underdeep:  deepest floor that descends = 9   (Deeps holds up to 20)
PROBE Underdeep->Nadir:  deepest floor that descends = 4   (Underdeep holds up to 10)
```

So a Deeps chamber at floor >= 10 can never descend, and the `Nadir` — which B.5 makes the endgame — is vertically reachable only from `Underdeep` floors 0-4. That is a second, undesigned structural gate stacked on the barrier gate B.5 specifies.

**The rule, and it needs no new randomness.**

> Floor 3 exits downward onto Floor 4. Floor 4 is in the same band as Floor 3 if that band has floors left, or the next band down if it does not.

**`floors_in_run` IS the sojourn time** in that chain — the chance lives in the count draw, one level up, rather than being rolled again per step. **No new stream, no new draw, no epoch.** The address does not change: `floor` stays a lattice coordinate within a band.

**Files:** `windows/worldgen/src/chamber.rs`

- [ ] **Step 1: Write the failing tests.** Descending from a band's **last realized floor** reaches floor 0 of the next band. Descending from any earlier floor stays in the band. The deepest band's last floor has no downward neighbour. And the property that was broken: **every realized floor of every band has a downward neighbour unless it is the last floor of the deepest band** — assert it over the whole lattice, not floor 0.

- [ ] **Step 2: Run red, and capture a BEHAVIOURAL red.** A compile error proves nothing about an assertion. The current rule is live, so a real red is available — take it.

- [ ] **Step 3: Implement.** One function. Keep `passages_from`'s sideways (same-band) candidates as they are; only the vertical rule changes.

- [ ] **Step 4: Run green.**

- [ ] **Step 5: Prove the new rule can fail** (Ruling 2). The property to demonstrate is that the band transition is **forced by the drawn sojourn** — a mutation that decouples the transition from `floors_in_run` must redden. State which half it kills and which it does not.

- [ ] **Step 6: Re-pin, fmt, gate, commit.** This changes which chambers are reachable, so Task 2b's witness should move — **check it, and say so**. If the witness does NOT move, either it is blind or this change did nothing; both are stop-and-report.
