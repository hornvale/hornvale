# The Grain Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the fine layer vary — emit the per-room micro-field a consumer can draw, and stop a room inheriting a categorical water kind from a grid cell 4096 times its size.

**Architecture:** Two producer changes plus one emit. `windows/locale`'s `describe` gains a blended-drainage water classification, mirroring what it already does for relief: blend the continuous underlay, apply the existing threshold function. `windows/scene`'s `surrounds` gains a `micro` object per cell and a cave mark. No client work, no new derivation, no seed draws.

**Tech Stack:** Rust 2024, `serde`, `serde_json`, `libm` only. `cargo nextest`. No new dependencies.

## Global Constraints

Copied verbatim from the spec and the repo's `CLAUDE.md`; every task's requirements implicitly include these.

- **Dependency allowlist**: `serde`, `serde_json`, `libm` only, workspace-wide. No new crates.
- **Layering**: `kernel/` → `domains/*` → `windows/*` → `cli/`. A domain depends on `hornvale-kernel` and nothing else. Enforced by `cli/tests/architecture.rs`.
- **No `HashMap`/`HashSet`, no wall-clock time.** `BTreeMap`/`BTreeSet`/`Vec` only. Enforced by `clippy.toml` `disallowed-types` with `-D warnings`.
- **Every crate sets `#![warn(missing_docs)]`.** Every new public item, field and variant gets a one-line doc comment.
- **Quantize at emit only** (decision 0033): serialized floats go through `hornvale_kernel::quantize` at the serialization boundary, never in the compute path.
- **Type audit is default-deny.** Any untagged primitive at a `pub` boundary fails `make gate`. Every new `pub` field must be added to its struct's `/// type-audit:` line. **A tag goes stale silently when a signature changes** — see `tools/type-audit/CLAUDE.md`.
- **Not an epoch.** No task in this plan may add a seed draw, change stream consumption order, or touch a seed-derivation label. If a task appears to need one, STOP and report.
- **`cargo fmt` is the final step before every commit.** Skipped fmt is this project's most common review finding.
- **Run cost-ordered**: `cargo fmt --check` and `cargo clippy` first, then `cargo test -p <crate>`, and only `make gate` at the end.

/// The sub-cell micro-field at a room: four independent axes in `[-1, 1]`,
/// each drawn from the room's own address noise, so a walk through
/// homogeneous biome still varies room to room.
///
/// A scene-side type rather than a re-export of `hornvale_locale::MicroField`,
/// for the reason every other float on this schema is: the wire type carries
/// the emit-boundary quantization (decision 0033) and the producer's type
/// carries the compute-path value. Coupling the published schema to a
/// window's internal struct would make a refactor there a cross-repo schema
/// change here.
///
/// **Not `Option`.** Every room has a micro-field — it is a pure function of
/// the room's address and the world seed — so an absent value would mean
/// "this emitter chose not to say", which is the exact confusion the
/// `is_here` gate on the fields above created. See this module's doc.
/// type-audit: bare-ok(ratio: relief), bare-ok(ratio: aspect), bare-ok(ratio: wetness), bare-ok(ratio: openness)
#[derive(Debug, Clone, Copy, PartialEq, Serialize)]
pub struct Micro {
    /// Micro-relief, hollow (`-1`) to rise (`+1`).
    #[serde(serialize_with = "hornvale_kernel::quantize::quantize_serde::f64_field")]
    pub relief: f64,
    /// Slope aspect / insolation, shaded (`-1`) to sunlit (`+1`).
    #[serde(serialize_with = "hornvale_kernel::quantize::quantize_serde::f64_field")]
    pub aspect: f64,
    /// Local wetness, dry (`-1`) to wet (`+1`). **Address noise, not
    /// hydrology** — it does not say where the water is, and a consumer must
    /// not band a water kind from it. `water` is the field that answers that.
    #[serde(serialize_with = "hornvale_kernel::quantize::quantize_serde::f64_field")]
    pub wetness: f64,
    /// Canopy openness, closed (`-1`) to open (`+1`).
    #[serde(serialize_with = "hornvale_kernel::quantize::quantize_serde::f64_field")]
    pub openness: f64,
}
