## Global Constraints

- **Two gates, neither implies the other.** `make gate-commit` does not scan `clients/`. `make game-check` is the only gate for `clients/game`, and it runs `cargo clippy --all-targets` on both client crates — **an example or test file left behind that does not survive clippy will red the gate.**
- **Byte-goldens under `windows/vessel/tests/fixtures/` are NOT written by `make rebaseline`.** Only `make rebaseline-goldens` (`REBASELINE=1`) writes them, and `gate-commit`'s sub-floor tier does not run the tests that read them. Any prose change needs both.
- **`clients/vessel/src/transcript.ts` and `clients/vessel/wasm/drive.mjs` parse transcript strings** and are outside the cargo workspace. A change to sim prose may need both; `make vessel-check` is their gate.
- **Never `| head` an enumeration** that will become a "the N sites are…" claim.
- **A function can be real, called, tested, and off the path a player drives.** Before fixing behaviour X at function F, prove F is on the path: reproduce it, or break F deliberately and watch the game change.
- **A test can go vacuous rather than red.** An `if let Some(...)` guard silently stops asserting. Point tests at real accessors (`s.position()`, `s.day()`), not at prose.
- No `HashMap`/`HashSet` (`clippy.toml` `disallowed-types`); no wall-clock time.
- Every crate sets `#![warn(missing_docs)]` — every new public item, field and variant needs a doc line.
- Run `cargo fmt` as the final step before every commit.
