# The Rail Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the five rungs on the ladder's frontier — `intransitive-frame`, `property-predication`, `locative-predication`, `person-deixis`, `polar-question` — and publish the frontier itself so the build-next list stops being computed by hand.

Interrogative force is an operator over a clause, never a field on it, because `Clause` is fact-shaped (decision 0266) and a question asserts nothing.

```rust
/// The rungs whose every presupposition is covered but which are not
/// themselves — the build-next list.
///
/// **The direction this computes, stated because a reader will assume the
/// other one.** A rung is on the frontier when its DEPENDENCIES are
/// satisfied, which is `demands` minus the rung's own `introduces` token.
/// It says nothing about whether the rung is cheap, only that nothing stands
/// between it and being built. A rung with three unbuilt dependencies is not
/// on the frontier however easy it looks.
fn ladder_frontier(entries: &[Entry]) -> Vec<String> {
    entries
        .iter()
        .filter(|e| !entry_covered(e))
        .filter(|e| {
            let own = ladder_introduces(e);
            e.demands
                .iter()
                .filter(|d| Some(d.as_str()) != own)
                .all(|d| demand_covered(d))
        })
        .map(|e| e.id.clone())
        .collect()
}

/// `(met, total)` over every `(entry, demand)` pair a corpus states.
fn demand_instance_coverage(entries: &[Entry]) -> (usize, usize) {
    let mut met = 0usize;
    let mut total = 0usize;
    for entry in entries {
        for demand in &entry.demands {
            total += 1;
            if demand_covered(demand) {
                met += 1;
            }
        }
    }
    (met, total)
}

/// **The syncretism, and exactly what it costs the backward read.**
///
/// English spells `are` for 2sg, 1pl, 2pl and 3pl, and `were` likewise, so
/// the copula paradigm — injective since Common had one — is not any more.
/// The FORWARD direction stays total: every (tense, number, polarity,
/// person) has exactly one surface. The BACKWARD direction cannot recover
/// person from `are` and returns a canonical row instead.
///
/// This is the same posture the round-trip property already takes toward
/// adjuncts: a loss that is PINNED rather than papered over, so a future
/// campaign that adds a person-recovering signal (subject agreement, say)
/// arrives as a red test.
#[test]
fn the_copula_paradigm_is_total_forward_and_syncretic_backward() {
    // Forward totality: every combination has a form.
    for tense in [Tense::Present, Tense::Past] {
        for number in [Number::Sg, Number::Pl] {
            for polarity in [Polarity::Pos, Polarity::Neg] {
                for person in [Person::First, Person::Second, Person::Third] {
                    let _ = copula_surface(tense, number, polarity, person);
                }
            }
        }
    }
    // Backward loss, stated by name: these four rows share one surface.
    let shared: Vec<&'static str> = [
        (Number::Sg, Person::Second),
        (Number::Pl, Person::First),
        (Number::Pl, Person::Second),
        (Number::Pl, Person::Third),
    ]
    .iter()
    .map(|(n, p)| copula_surface(Tense::Present, *n, Polarity::Pos, *p))
    .collect();
    assert!(
        shared.iter().all(|f| *f == "are"),
        "the present positive syncretism is exactly these four rows: {shared:?}"
    );
}
```
