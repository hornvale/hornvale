# The Shoal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Status:** COMPLETE — merged. See [the chronicle](../../../book/src/chronicle/the-shoal.md).

**Goal:** Give the sea its words. 79% of the world's rooms currently render
through a two-item catch-all, and the land clauses are applied underwater, so
a black smoker 2,500 m down reads "sun-warmed" and a kelp forest reads "dry".

**Architecture:** The locale grammar stops keying off the flat `Biome` and
keys off the `BiomeExpr` The Formations shipped. That is the whole reason
this is cheap: `OpenWater`'s pool can depend on its **stratum**, which the old
flat enum made awkward, and `micro_habitat` can consult the realm's **medium**
to know it is underwater.

**Design authority:** `docs/superpowers/specs/2026-07-28-the-stratum-design.md`
(The Stratum), campaign 2 — **minus its name-gloss epoch**, which is split
into its own campaign (see "Scope" below).

**Tech Stack:** Rust 2024, std + `serde`/`serde_json` only.

## Scope: the epoch is deliberately NOT here

The Stratum's campaign 2 bundles marine prose with O1's name-gloss epoch
(variants entering settlement names). This plan implements **only the prose**.
The epoch is split out because:

- The prose fix is the largest visible gain in the whole sequence and carries
  **no** determinism risk — `windows/worldgen` does not import
  `hornvale_locale` at all, so room prose is never a genesis input and no world
  byte can move.
- The epoch rewrites every settlement name in every world, moves census
  goldens, and therefore needs a **census regeneration** — an authorization
  carve-out. Bundling a carve-out with a zero-risk change makes the zero-risk
  change wait, and makes the carve-out harder to review alone.

O1 remains resolved (yes, variants in glosses); it is simply a later campaign.

## Global Constraints

- **No world byte may move.** Room prose is presentation only. The seed-42
  fixture in the gate is the referee; never rebaseline it here.
- **Land prose must not move, except for `Ice` and `Shrubland`.** Every other
  land formation keeps its existing pool contents *and weights*, so its draws
  are unchanged. `Ice` and `Shrubland` currently fall through to the catch-all
  and are part of the 79% being fixed — their prose changes on purpose.
- **Seed 42's flagship is tropical seasonal forest**, so the possession
  transcripts and the almanac must be byte-identical. If they move, a land pool
  was disturbed.
- **No new concepts, no epoch, no census regen.** If a task appears to need
  one, STOP.
- **`#![warn(missing_docs)]`**, single-line `type-audit:` tags, valid `bare-ok`
  classes only (`ratio, count, index, constructor-edge, envelope,
  identifier-text, prose, artifact, diagnostic-value, render-internal, flag`).
- Run `cargo fmt` before every commit. Full `make gate` at the close.

Give `micro_habitat` the expression and branch on the medium:

```rust
fn micro_habitat(micro: MicroField, expr: BiomeExpr) -> String {
    match expr.realm.medium {
        Medium::AirOverRock => land_micro_habitat(micro),
        Medium::Water => water_micro_habitat(micro, expr.stratum),
    }
}
```

`land_micro_habitat` is the current body, moved verbatim — it must not change.

`water_micro_habitat` reads the same `MicroField` in the water's own terms:

```rust
/// The water column's habitat clause. The same micro-field, read as water
/// reads it: relief is the seafloor beneath, aspect is light (which only
/// means anything where light reaches), and wetness — meaningless in the sea —
/// becomes the set of the current.
fn water_micro_habitat(micro: MicroField, stratum: Stratum) -> String {
    let relief = if micro.relief > 0.33 {
        "over a seamount"
    } else if micro.relief < -0.33 {
        "over a trough"
    } else {
        ""
    };
    // Light is only a description where light arrives.
    let light = if matches!(stratum, Stratum::Epipelagic | Stratum::Surface) {
        if micro.aspect > 0.33 {
            "sunlit"
        } else if micro.aspect < -0.33 {
            "in blue shadow"
        } else {
            ""
        }
    } else {
        ""
    };
    let current = if micro.wetness > 0.33 {
        "swept by a current"
    } else if micro.wetness < -0.33 {
        "in slack water"
    } else {
        ""
    };
    [light, current, relief]
        .into_iter()
        .filter(|s| !s.is_empty())
        .collect::<Vec<_>>()
        .join(" ")
}
```
