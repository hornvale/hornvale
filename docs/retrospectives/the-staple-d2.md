# The Staple D2 — retrospective

*The chronicle tells what the world gained. This record tells what the
campaign had to learn before it could say so.*

## The first run was not evidence

The first integrated 200-seed run completed, but its disabled arm passed
`1.0` as a pressure factor where the identity shortfall is `0.0`. Its control
identity comparison was therefore not the existing demographic control. The
run remains in the ledger as an invalid measurement record. The argument for
rerunning was substantive repair of the experiment, not inspection of a
different output line; one corrected replacement was authorized and became
the sole verdict source.

That distinction matters for expensive probes. A complete process with the
wrong control is not a failed verdict and not a valid verdict. Preserve it,
name the defect, repair the mechanism, and keep the replacement count honest.

## The smallest genuine exchange was typed

An aggregate food stock would have made gifts and redistribution, not
reciprocal exchange. Two non-convertible types forced the mechanism to expose
what each side could offer and what each side actually lacked. The fixed 1:1
bundle keeps this rung legible while leaving typed claims, conversion, and
negotiated prices for later campaigns.

The implementation also made the phase boundary explicit. Existing
production is partitioned without a new draw; clearing is local and
deterministic; consumption is typed; pressure receives only the bounded
shortfall signal; tribute remains last. The invariant tests name the direction
of each relationship and require nonzero fixtures where an ordering claim
could otherwise pass vacuously.

## The probe answered ownership, not everything downstream

Exchange activated in 178/200 worlds and stayed below every instability pole:
6/200 settlement-count breaches, 1/200 collapse-share breach, and 0/200
alive-at-now breaches. This accepts D2 and gives the climate-to-city link an
owner. It does not establish a catchment ceiling, a city, durable census
columns, or a financial instrument family.
