# The Effacement — retrospective

Process lessons, not product.

## "More cases" is the wrong answer to an unsourced claim

The stance verb could not express swimming, walking a sea floor, flying, or
being in a boat. The apparent fix was to add those cases. The actual problem
was that the renderer had no source for *any* of them: it knew the medium and
the band, and nothing about legs, fins, or wings.

Enumerating contexts a system cannot detect makes it more confidently wrong, not
more correct.

**Lesson:** when a rendered claim looks like it needs more branches, ask what
supplies it. If the answer is "a default in the template", the branches are not
the fix — either source the claim or stop making it. The ideonomy *source*
prompt is what surfaced this; the fork had been framed as "how many verbs" and
the useful question was "who says".

## A test defended the Constitution and was right to

`the_sun_never_leaves_the_visible_bodies_list` blocked what looked like an
obvious cleanup: filtering the almanac's body list by occlusion. Its battery
enforces "coarse constrains fine" — tier 1 may add structure beneath tier 0's
`ConstantSun`, never retract it — so `bodies` is a roster, not a visibility
claim, and filtering it is a constitutional violation.

The registered followup had said "either occlude it or rename the label", and
the first option was unavailable for a reason nothing in the almanac's own code
would have revealed. Renaming was not the lesser fix; it was the only correct
one.

**Lesson:** a failing test with a *deliberate-sounding name* deserves reading
its module doc before deciding what to do about it. The signal is strong: nobody
names a test "X never leaves Y" by accident.

## Owner framing beat the recommendation

The fork was offered as three options with "presence, not posture" recommended.
The owner chose the stronger one — no PC at all — which turned out to be both
more honest and simpler to implement, since it removed a branch rather than
replacing it.

Worth recording because the recommendation was hedging toward continuity, and
the sharper answer was available the whole time.

## Follow-ups

- **A sourced stance** remains possible and now has a marked seam. It wants the
  liveness layer to expose a real activity (moving, resting, feeding) plus the
  species' locomotion, and it would be a genuine enrichment rather than a
  guess.
- **Command responses still address the player** ("You break the surface"),
  deliberately: the command is their source. If the voice is ever taken further,
  that is the next line to examine, and it is a different argument.
- **Nine of twelve kingdom×energy combinations** remain unused in the exotic
  candidate table — authoring headroom, unchanged by this campaign.
