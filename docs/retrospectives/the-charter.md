## What the checks establish

The compiler checked the envelope's structure, not the truth or sufficiency of
its claims. Removing the real `loom` roster entry compiled and contradicted
the declared contract; rewriting the declaration as satisfied did not change
the observation. This extends [The Tackle's existing lesson](the-tackle.md#3-what-the-surviving-control-proved-is-narrower-than-the-acceptance-test-works):
a control proves only its exercised property, on its named object. The census
panel initially passed canonical-host cases even when prefix or relative-path
recognition was omitted. Wrong-host refusal cases and separate omission mutants
made those forms discriminate. Independent authorship helps expose a wrong
declaration; it does not prove that an oracle covers every relevant behavior.

## Independence has several boundaries

Both adopters enrolled against one frozen host without shared semantic edits.
They still shared Cargo.lock, and calling a pure lab API still compiled its
27 added local packages. Independent files, independent builds and independent
meaning must be evidenced separately. Preserve exact bootstrap, reviewed,
integrated, measured and final-tested identities; a green result belongs to
the tree that actually ran. The existing pipeline still governs admission.

harness that missed the host's nested process groups, cleanup errors that lost
samples, and interrupted zero-exit commands that lost stdout. Scoped RED/GREEN
fixtures closed these defects before sampling. Tests must reproduce the real
process topology and abnormal exits. A cleanup failure now preserves available
raw evidence and the owned directory before aborting later work.
