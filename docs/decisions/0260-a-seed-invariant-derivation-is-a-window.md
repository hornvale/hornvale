# 0260. A seed-invariant derivation is a window, not a census metric

**Status:** Accepted (2026-08-25) · **Decider:** Nathan · **Relates:**
[0011](0011-studies-are-data-metrics-are-code.md),
[0016](0016-studies-preregister-hypotheses.md),

[0259](0259-conceptual-deficiency-is-derived-not-authored.md);
[The Confidant](../../book/src/chronicle/the-confidant.md)

In the context of forty-five per-species metrics that measured out constant
across a thousand worlds, we decided that **a derivation whose value does not
vary with the seed does not belong in the census registry — it belongs in a
window that renders it once, from one world** — accepting that its numbers are
no longer queryable in duckdb alongside census columns.

## Context

The three felt-state measures (`reportable_fraction`, `collapse_ratio`,
`misreport_distance`) were built as lab metrics, one family per each of the
fifteen peoples. A thousand-seed census run answered a question nobody had
thought to ask of them: **all forty-five columns were identical on every row.**

The mechanism was then verified rather than assumed, because
constant-across-seeds has two causes and only one is benign. These metrics read
the real per-world lexicon, then branch on whether the culture *has* the
concept — which is exposure-determined, and exposure derives from authored
species attributes. The word's *form* varies by seed; its *existence* does not.
The columns were correctly seed-invariant, not broken reads.

That is disqualifying on two counts, and the second is the serious one.

1. **Cost.** The census pays for these on ~2,000 world-builds every refresh, to
   learn what one world already knows. Measured, they were ≈2.95 ms per metric
   per world — roughly 3× the stated tolerance — and nine committed studies
   select `"metrics": "all"` with no opt-out flag, so the tax would have been
   permanent.
2. **A constant column cannot detect drift, which is the census's whole job.**
   It will move all thousand rows at once or never. **A flat column looks
   exactly like a well-behaved one** — the healthiest-looking thing in the
   table, and inert.

The repository already held the precedent and the campaign had put its work on
the wrong side of it: `windows/sentiment` is "a pure, world-invariant
derivation … computable before any seed exists. No world is built." It is a
window. These are the same shape.

## Consequences

- **`render_confidant_report` is a pure function in `windows/lab`** that builds
  one world at `Seed(42)` and renders fifteen rows, published as
  `docs/audits/the-confidant-report.md`, regenerated by
  `scripts/regenerate-artifacts.sh` and drift-checked like any other artifact.
  The instrument itself — the five functions that compute the three measures —
  moved *home* and not a byte, verified by diffing each body against a
  pre-reshape copy.
- **A schema bind dissolved with it.** Registering forty-five metrics changes
  every all-metrics study's schema, so the committed `rows.csv` no longer
  matched and every census-reading test in the commit gate's roster panicked
  identically — which meant the metrics could not commit, and the census that
  would fix that needed a reference containing the metrics. Unregistered, there
  is no schema change and no bind. **The blocker that cost four census runs was
  downstream of a shape error, not a real constraint.**
- **What we accept:** these numbers are no longer joinable against census
  columns in the analysis harness. Fifteen rows are more usable than
  forty-five columns replicated a thousand times for the question actually
  being asked, and if exposure ever becomes seed-dependent — varying by biome,
  or by contact between peoples — registering them *then* is easy, and the
  census is then the right home.
- **The test that would have caught this earlier is a non-degeneracy check on a
  new metric family**, run before registration rather than after: does this
  column take more than one value across the seeds it will be computed on? The
  campaign ran it late and paid for the lateness in canonical-box time.
