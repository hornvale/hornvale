# 0886. D2 uses two typed subsistence commodities

**Status:** Proposed at G3 (2026-09-06) · **Decider:** Nathan review pending ·
**Campaign:** The Staple D2 · **Relates:** [0826](0826-a-dynamics-probe-falsifies-on-a-count-against-an-existing-ceiling.md)

D2 must model actual exchange, not merely redistribution. It therefore uses
two fungible-within-type, non-convertible subsistence commodities, with total
production preserved and deterministically split by existing terrain/climate
state. Population is not inventory; existing `stores` remains non-edible
wealth.
