# 0750. `bench` is concept accession epoch 20; the dwelling derivation adds no stream

**Status:** Accepted (2026-09-04) · **Decider:** Nathan ·
**Campaign:** The Housemark · **Relates:**
[0069](0069-fine-position-is-never-serialized.md) (interiors remain derived),

[0618](0618-a-descent-key-makes-the-plan-a-save-format-contract.md)

The Housemark consumes no randomness, adds no stream, writes no fact, and does
not serialize an interior. Adding `BENCH` nevertheless registers a new concept
inside every saved world's `ConceptRegistry` and assigns it language roots.

We therefore decided that **`bench` occupies concept accession epoch 20**,
accepting the additive world, concept, dictionary, proto-root, coverage, and
solitary-tongue fixture movement. This is an accession epoch only: no existing
cohort is reordered and no seeded derivation epoch changes.

The measured seed-42 world fixture gained only the additive `bench` concept
object, and the goblinoid root-table fixture gained one additive `bench` row.
The full non-census regeneration moved only projections of that accession and
chamber-rendering outputs. No ledger fact, census, lab golden, stream roster,
or unrelated world data moved.
