# The Charter

The Digest can now assemble checked context for a local editing task. A
contributor owns its requirements, instructions and finite observations beside
its package; the host discovers enrolled packages, selects the requested scope,
builds and collects current evidence, and renders their union. Adding either
of the first two contributors required no semantic edit to the host.

```sh
make context-prepare
make context SCOPE=domains/thing
make context SCOPE=windows/lab/src/publish.rs
```

Preparation may fetch dependencies and builds every Digest member. Context
then uses locked, offline builds of the selected contributors. It reads the
current checkout; an old report is not an accepted input. The
[command guide](https://github.com/hornvale/hornvale/blob/main/tools/digest/README.md)
explains enrollment, preparation failures and the supported Unix hosts.

## Two independent adopters

The Thing contributor composes the real Settlement and Thing registrars. It
checks registration, compares source and component rosters in both directions,
and checks owned and explicitly borrowed concept names. These observations
establish finite roster and ownership agreement, not worldgen wiring, save
compatibility or item behavior.

The census-publication contributor calls the existing pure canonical-host
guard. Its finite panel includes allowed cases and wrong-host refusals for
both study-name forms and official output-path forms. A separate observation
checks source and compiled canonical-host agreement. Queue authoring remains
an authored, unchecked requirement: collecting this context runs no census,
publication or queue operation.

Both packages were developed from the same reviewed bootstrap, on separate
branches, and accepted by the same frozen host. Each changed four package
files and the shared Cargo lockfile. Integration preserved the reviewed
package trees and all 22 external dependency records, adding 27 local package
records. That is evidence for independent enrollment, with shared build
metadata still requiring reconciliation. The census package compiles through
the lab dependency even though its observations call only a pure predicate.
File independence, compilation independence and semantic independence remain
three different claims.

## A declaration can be contradicted

A valid envelope names its expected observations separately from their
results. Missing required observations fail validation; unknown required
results and every explicit contradiction make the report unsuccessful.
Authored-only policy remains visibly unchecked. Stable namespace and outer
record ordering make the two real envelopes render identically in either
order without sorting away the order inside their evidence.

The behavioral counterexample removed `loom` from the actual Thing source
roster in an isolated checkout. The contributor rebuilt successfully and
reported `extra in component registry: loom`. Replacing its requirement text
with “The ownership requirement is satisfied.” changed the prose and left the
contradicting observations unchanged. Types check the shape of that declaration;
they do not establish its truth or the sufficiency of the chosen observations.

The host bounds process lifetime and output, isolates Git and build paths,
and withholds successful partial output until collection is complete. Its
qualification covers failures as well as the ordinary path. These are trusted
repository processes, not a security sandbox; the ownership contracts exclude
children that detach from the owned group or measurement session. Revision
and dirty state identify the checkout only incompletely, with no atomic source
snapshot or complete dependency fingerprint.

## Measured, with the limits retained

The [qualification record](https://github.com/hornvale/hornvale/blob/main/docs/digest/the-charter-evidence.md)
contains the real successful and failing reports, both branch rosters, exact
source identities, lifecycle and mutation evidence, and every Mac and Linux
measurement: 72 command samples, including separate host builds, selected cold
requests and ten warm requests per workload on each host. An independent reader
could identify the declarations, checks, limitations and failing source from
three reports without opening the source or this conversation.

Warm medians for Thing, census and combined context were 0.396 / 0.513 / 0.621
seconds on the measured Mac and 1.033 / 0.805 / 1.145 seconds on the measured
Linux host. The record preserves ranges, load, raw memory units, cold costs
and missing attribution. Ten consecutive requests are not a long-term latency
guarantee, so no service-level target was adopted and operational caps stayed
unchanged. Both hosts passed all 95 Digest tests; two canonical stage jobs
also passed 5,355 workspace tests and the following doctests.

This is a bounded continuation of [The Digest](./the-digest.md). It establishes
an extensible context surface, not semantic independence of arbitrary changes,
complete provenance, automatic activation, permission to narrow gates, a
self-writing Book or a replacement for human review. The larger federation
program remains open.
